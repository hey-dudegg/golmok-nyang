마일스톤 종료 처리: $ARGUMENTS

1. INDEX 기준으로 보고한다: 계획 대비 완료·미완료 작업 / 막힌 것 / 내가 답해야 할 P / 이번에 바뀐 것(C).
2. 미완료 작업은 다음 마일스톤으로 넘길지, 버릴지 나에게 묻는다.
3. /cleanup 규칙대로 문서를 정리한다.
4. history/LOG.md를 history/LOG-M{n}.md로 이름을 바꾸고 새 LOG.md를 시작한다. TOKEN_USAGE에 분석 안 된 줄이 있으면 token-optimizer에게 분석을 맡긴다.
5. 다음 마일스톤 범위를 2안으로 제안한다 (작게 / 크게).
6. 여기서 멈추고 내 승인을 기다린다. 승인 전에는 다음 작업을 시작하지 않는다.
