문서를 정리해라. 삭제는 하지 않고 archive로 옮기기만 한다.

1. 대체·폐기된 D, 완료된 R, 해결된 P를 docs/archive/ 로 옮긴다 (파일명: DECISIONS-M{n}.md 처럼 마일스톤별).
2. 크기 제한(INDEX 80줄, R 5줄, D 3줄, P 3줄)을 넘는 항목은 의미를 바꾸지 않고 요약한다.
3. INDEX와 원본 파일의 ID가 일치하는지 검사한다. 빠졌거나 남는 ID가 있으면 목록으로 보고한다.
4. INDEX의 "보관됨"을 ID 범위로 갱신한다.
5. 무엇을 옮기고 요약했는지 5줄 이내로 나에게 보고한다.
