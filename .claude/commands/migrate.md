기존 docs/의 문서를 새 구조로 옮겨라. 한 번만 실행하는 명령이다.

먼저 기존 문서별 줄 수와 항목 수(P-, D- 등)를 알려라.

1. 기존 docs/ 파일 전체를 docs/archive/legacy/에 복사해 보존한다.
2. 복사를 확인한 뒤 docs/의 파일을 새 형식으로 다시 쓴다. 기존 ID(P-, D-)는 번호를 그대로 유지한다.
3. 내용을 R(요구) / D(결정) / P(논의 필요)로 분류해 REQUIREMENTS / DECISIONS / PENDING에 쓴다. 길면 의미를 바꾸지 않고 요약한다.
4. 분류가 불확실한 항목은 임의로 옮기지 말고 "분류 불가" 목록으로 따로 보고한다.
5. 기존 STATUS 내용은 INDEX의 역할별 현황으로 옮긴다. 기존 PLAN은 새 PLAN 형식에 맞춰 정리한다.
6. INDEX를 작성하고 LOG에 [이관] 기록을 남긴다. 과거 이력은 문서에 근거가 있는 만큼만 LOG와 CHANGELOG에 옮기고, 추측해서 만들지 않는다.
7. 새 구조에 없는 기존 파일(STATUS.md 등)은 legacy 복사본이 있는 것을 확인한 뒤, 나에게 물어보고 docs/에서 뺀다.
8. 끝에 매핑표(기존 항목 -> 새 위치, 항목 수 일치 여부)를 보고하고 내 승인을 받는다.
