커밋·푸시 전 보안 점검을 해라. 아무것도 커밋하거나 푸시하지 않는다.

1. `git status`와 커밋 대상 변경분(`git diff --cached`, 없으면 `git diff`)을 확인한다.
2. 아래가 들어 있는지 찾는다.
   - 비밀값: API 키, 토큰, 비밀번호, 개인 키, 접속 문자열
   - 시리얼·라이선스 키, 계정 ID, 사내 서버 주소·IP, 내부 URL
   - 실명, 사내 이메일, 전화번호 등 개인 정보
   - .private/TERMS.md 왼쪽 열의 실제 명칭 (사내 시스템명, 회사명, 고객사명)
   - 사내 데이터 파일, DB 덤프, 내부 문서 원본
3. .gitignore에 있어야 할 파일이 추적되고 있는지 확인한다 (`git ls-files`).
4. 결과를 보고한다: 문제 없음 / 문제 목록(파일, 줄, 종류, 권장 조치). 실제 비밀값은 보고에 다시 쓰지 말고 앞 4자리만 보인다.
5. 수정은 내 승인 후에만 한다. 사내 명칭은 TERMS의 공용 용어로 바꾸는 것을 제안한다.
