## 11. 열린 질문 (P 후보)와 추천안

| 후보 | 질문 | 추천 |
|---|---|---|
| P-O1 | 오브젝트 기능 기본값: 1단계에서는 꺼짐(어드민/`?props=1`로 켬) vs 바로 켜짐 | **종료(D-120)**: 개발 중 꺼짐, 출시 때 상자·자동차 켬. 켜기 조건 = 4A-3 T1~T8 통과. |
| P-O2 | 담 "위" 행동을 뒷담(높이 2.1m, 화면 위로 벗어남)에 둘지, 낮은 담 별도 오브젝트로 할지 | **낮은 담 별도 오브젝트**(0.8m). 뒷담은 시야 모드 B(1.2m)일 때만 후보. |
| P-O3 | 명소 연동(예: 한옥 지역엔 평상, 항구엔 어구 상자)? | 1~3단계 제외(D-26 명소는 이름만). 필요하면 R로 별도 등록. |
| P-O4 | 자동차 비례: 양식화한 작은 차(2.2m) vs 실물 크기(화면 밖으로 잘림) | **D-115로 잠정**: 본네트 길이 ≈ 고양이 몸길이 x4, 화면 밖 조금 넘침 허용, 시연 후 확정. |
| P-O5 | 비·눈 날씨(차 밑 비 피하기)를 이 작업에 포함? | 제외. 현재 날씨는 clear/haze/mist뿐이라 별도 요구(R)로. |
| P-O6 | 손님·호스트가 지점 쟁탈하는 연출 포함? | 3단계 이후. 지금은 점유 시 대체. |
| P-O7 | 차 종류 확장(트럭·오토바이·자전거)과 주차 규칙 | 1단계는 소형차 1종. 확장은 표 한 줄씩. |
| P-O8 | "차 밑 숨기" 상태에서 사용자 쓰다듬기를 막는 정도(완전 불가 vs 반응만 부정) | **반응만 부정**(막지 않음). 사용자 경험이 끊기지 않게. |
