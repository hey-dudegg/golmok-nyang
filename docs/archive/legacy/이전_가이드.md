# 골목냥을 "코드"와 로컬 CLI로 옮기는 방법

준비물은 이 폴더의 두 가지입니다.
- `CLAUDE.md` — 저장소 루트에 두면 Claude가 매번 자동으로 읽는 프로젝트 안내서
- `prototype/index.html` — 프로토타입 v2 원본(아티팩트에서 그대로 받은 것)

두 곳 모두 **GitHub 저장소 하나**를 중심으로 이어집니다. 저장소 이름은 `golmok-nyang`을 제안드립니다.
처음엔 **비공개(Private)**로 만드시는 걸 권합니다.

## 1단계. 저장소 만들기 (한 번만)
1. github.com → New repository → 이름 `golmok-nyang`, Private, README 없이 생성
2. 이 프로젝트 파일에서 `handoff/CLAUDE.md`와 `handoff/prototype/index.html`을 내려받기
3. 저장소 첫 화면의 "uploading an existing file"로 두 파일을 올리기.
   `index.html`은 `prototype/` 폴더 안에 두면 CLAUDE.md 설명과 맞습니다.
   (파일명 입력칸에 `prototype/index.html`처럼 쓰면 폴더가 생깁니다.)

## 2단계. "코드"(claude.ai/code)에서 시작
1. https://claude.ai/code 접속 → GitHub 연결(처음 한 번) → 저장소 `golmok-nyang` 선택
2. 첫 요청 예시: "CLAUDE.md를 읽고 '다음 할 일 0번'(파일 나누기)부터 해 주세요. 끝나면 PR로 올려 주세요."
3. 코드는 클라우드 컨테이너에서 작업되고, 결과는 브랜치·PR로 저장소에 남습니다.
   PR을 합치면(merge) 그다음 세션이나 로컬에서도 그대로 이어집니다.

## 3단계. 내 컴퓨터의 CLI로 옮기기
1. Claude Code 설치 (터미널에서 하나 선택)
   - macOS/Linux: `curl -fsSL https://claude.ai/install.sh | bash`
   - npm이 있으면: `npm install -g @anthropic-ai/claude-code`
   - Windows는 PowerShell에서 `irm https://claude.ai/install.ps1 | iex`
2. 원하는 로컬 폴더에서 저장소 받기
   ```
   git clone https://github.com/<내 아이디>/golmok-nyang.git
   cd golmok-nyang
   ```
3. `claude` 실행 → 처음엔 브라우저로 claude.ai 계정 로그인
4. 그대로 이어서 요청하면 됩니다. CLAUDE.md는 자동으로 읽힙니다.
   웹에서 하던 세션 자체를 가져오고 싶으면 `claude --teleport`로 고를 수 있습니다.
5. 화면 확인: `python3 -m http.server 8000` → 브라우저에서 http://localhost:8000/prototype/

## 알아 두실 점
- 웹 "코드"와 로컬 CLI는 대화 기록이 아니라 **저장소(코드 + CLAUDE.md)**로 이어집니다.
  중요한 결정은 CLAUDE.md에 적어 두면 어디서든 똑같이 이어집니다.
- 로컬에서 작업한 뒤에는 `git push`해야 웹 "코드"에서도 보입니다(반대 방향은 `git pull`).
- 프로토타입은 로컬에서 로그인·DB 기능 없이 동작합니다. 그 부분은 '다음 할 일 3번'(Supabase)에서 대체합니다.
- 기획서·행동 설계 문서는 claude.ai 링크로 계속 열립니다(CLAUDE.md 참고 문서 목록).
