# 골목냥 (golmok-nyang)

길에서 만나는 길고양이를 웹으로 옮기는 프로젝트입니다. 목적은 오직 **보는 즐거움(심미)**입니다.
동네(시/군/구 → 행정동)마다 복슬한 고양이가 새끼부터 성체까지 무작위로 생겨 그 동네에 귀속되고,
성격에 맞는 행동을 스스로 합니다. 방문자는 구경만 할 수 있고, 쓰다듬기·츄르 주기·고양이 말
("마-아", 하악, "라오오- 니겅니겅니겅")로 말 걸기는 회원가입 후에 할 수 있습니다.
장면을 캡쳐해 자유게시판에 공유합니다.

## 대원칙
- **비용 0원.** 외주, 모델 구매, 유료 API, 유료 서버를 쓰지 않습니다.
- 사용자에게는 항상 **한국어 존댓말**로 답합니다. 반말 금지.
- 되돌리기 어려운 작업(배포, 저장소 공개 설정, 데이터 삭제, 외부 계정 변경)은 사용자 확인 후에 합니다.

## 기술 결정 (2026-10-11 확정)
- **three.js 0.160** (CDN `cdn.jsdelivr.net/npm/three@0.160.0`)로 절차적 뼈대 + 셸(shell) 털 렌더링.
  Blender, AI 3D 변환(TRELLIS 등), AI 영상 파이프라인은 쓰지 않습니다.
- 교감 반응에 AI 호출 없음. 성격 × 교감 종류별 확률 반응표로 처리합니다.
- 생애주기: 동네 코드 + 날짜로 브라우저가 결정적으로 계산. 생애 단계가 바뀌면 재생성.
- 지역: 처음엔 시/군/구 256곳마다 마스코트 1마리, 사용자가 늘면 행정동 3,558곳. 지금 프로토타입은 1~2마리.
- 이름: 이웃이 1인 3개까지 제안, 좋아요 상위 10 랭킹, 1위가 고양이 이름.

## 행동 엔진 설계 요지
- 입력(장면 자극·이웃 교감·시간대·성격 6축) → 상태(욕구 4: 에너지·배고픔·지루함·안심 /
  감정 8: 편안·호기심·신남·애정·경계·두려움·짜증·졸림, 0~1, 성격 평소값으로 감쇠)
  → 행동 선택 → 실행 4겹(자세 → 이동·점프 → 표정 레이어 → 시선·숨쉬기)
- 시계 두 개: 주요 행동 60~120초, 작은 동작 5~20초. 교감·자극은 즉시 끊고 반응.
- 점수 = w·P·N·E·T·R·A, 상위 5개 중 점수 비례 추첨(온도 조절).
  반복 방지: 최근 5개 ×0.3, 같은 분류 연속 ×0.6, 오늘 처음 ×1.3.
- 10개 분류 51가지 행동. 장면 지점(높은 곳·상자·햇볕 자리·숨을 곳·비비기 자리).
  점프는 고양이 키 4배까지, 높은 담은 두 번에.
- 뼈대 확장: 등 4마디 + 굽힘, 귀 2축 좌우 독립, 눈꺼풀 모양, 턱 뼈, 꼬리 마디별 부풀림·말기,
  발 2마디 IK, 수염 회전.
- 행동은 DSL(`behavior('box_peek', {...})`)로 데이터 정의. `?debug`로 조정 화면.
- 새 교감 '물건 놓아 주기'(종이상자·낚싯대 장난감). 놓은 상자는 동네에 하루 유지.

## 배포안 (서버리스, 무료 등급)
- 정적 호스팅: Cloudflare Pages. 백엔드: Supabase 무료(카카오·Google 로그인, DB, 파일, 실시간, RLS).
- Supabase는 7일 무요청 시 정지되므로 GitHub Actions로 하루 한 번 요청.
- Firebase는 쓰지 않음(카카오 기본 미지원, Spark 요금제 Cloud Storage 불가).
- 프로토타입의 저장소 계층(Claude 아티팩트의 `window.claude.use` 기반 Caps: db·user·downloads·sample)을
  Supabase 어댑터 한 파일(약 200줄)로 교체. 화면·행동 엔진·동네 선택·캡쳐는 그대로.
- 공개용 anon 키만 코드에 넣고, service_role 등 관리자 키는 어디에도 넣지 않습니다.
- 이벤트 기록(30초 묶음), 앱 안 의견 보내기, Cloudflare Web Analytics. 이벤트에 이름·연락처 넣지 않음.
  개인정보 안내 페이지 필요.
- 계정(GitHub, Cloudflare, Supabase, 카카오 디벨로퍼스)은 모두 사용자 명의.
