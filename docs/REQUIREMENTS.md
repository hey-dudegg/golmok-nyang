# REQUIREMENTS
> 사용자의 요구와 팀장의 이해를 짝지어 기록한다. 항목당 5줄 이내. 번호 재사용 금지.
> 상태: 확인(이해를 사용자가 확인함) | 미확인 / 미착수 | 설계됨 | 구현중 | 완료 | 보류
> 이관 기준: 프로젝트 주제문과 docs/archive/legacy/ 문서. "프로토타입"은 Claude 아티팩트 Caps 기반 v2를 뜻한다.

## R-01 동네별 고양이 생성과 귀속
- 사용자 요구: "복슬한 고양이를 각 지역별로 애기부터 성체까지 랜덤하게 생성하여 지역에 귀속"
- 팀장 이해: 시/도 16곳 마스코트 1마리로 시작, 하위 단계는 비활성화(D-05, 2026-10-18 축소). 생애 단계는 D-04로 계산
- 상태: 확인 / 구현중 (프로토타입 v2는 1~2마리)
- 관련: D-04, D-05

## R-02 성격에 맞는 자율 행동 관상
- 사용자 요구: "고양이는 각자 개성에 맞는 행동을 무작위로 보이며, 웹 사용자는 이를 관상"
- 팀장 이해: AI 호출 없이 성격 6축 + 욕구·감정 상태로 51가지 행동을 확률 선택(D-07). 모션을 크게 늘림
- 상태: 확인 / 설계됨 (M2, M3에서 구현)
- 관련: D-02, D-03, D-07

## R-03 회원 교감 (쓰다듬기·츄르·고양이 말)
- 사용자 요구: "쓰다듬거나 츄르를 주거나 고양이 언어(마-아, 하악, 라오오- 니겅니겅니겅)로 소통하려면 회원가입"
- 팀장 이해: 구경은 비회원, 교감은 로그인 후. 반응은 성격×교감 확률표, 개냥이 약 20%, 속마음·행동 극성 일치(D-03,30)
- 상태: 확인 / 구현중 (프로토타입은 아티팩트 로그인, M4에서 Supabase로 교체)
- 관련: D-03, D-10, P-01

## R-04 캡쳐와 자유게시판
- 사용자 요구: "캡쳐해서 서로 공유할 수 있는 자유게시판"
- 팀장 이해: 장면 캡쳐 이미지를 Supabase 파일 저장소에 올리고 게시판 글로 공유
- 상태: 확인 / 구현중 (프로토타입 v2에 있음, M4에서 저장소 교체)
- 관련: D-08, D-10

## R-05 고양이 이름 짓기
- 사용자 요구: 이웃이 이름을 제안하고 투표 (이전 결정에서 확정)
- 팀장 이해: 세션당 5개 제안, 좋아요/싫어요, 싫어요>좋아요·신고 5개면 삭제, 좋아요 1위가 이름(D-31)
- 상태: 확인 / 구현중
- 관련: D-06, D-31

## R-06 물건 놓아 주기
- 사용자 요구: 새 교감으로 종이상자·낚싯대 장난감 놓아 주기 (2026-10-11 행동 설계)
- 팀장 이해: 놓은 상자는 그 동네에 하루 유지, 그 동네 이웃 모두에게 실시간으로 보임(D-39)
- 상태: 설계됨 (M3)
- 관련: D-07, D-39

## R-07 반응 수집과 개인정보 보호
- 사용자 요구: 공개 후 반응을 보고 조정 (2026-10-11 배포안)
- 팀장 이해: 이벤트 30초 묶음, 앱 안 의견, Cloudflare Web Analytics. 이름·연락처 미수집, 개인정보 안내 페이지
- 상태: 미확인 / 설계됨 (M4, M5)
- 관련: D-12, P-05

## R-08 구경 오세요 홍보하기
- 사용자 요구: 사진 버튼 옆 확성기 버튼, 누르면 자동 캡쳐 + 화면 위 가운데 안내창 5초, 누르면 그 지역으로 이동. 10초에 한 건, 먼저 누른 1명만, 나머지는 버림
- 팀장 이해: db acquire(10초 잠금) → 배포 후 Supabase RPC 잠금 + Broadcast. 1인 1분 쿨다운
- 상태: 확인 / 설계됨 (docs/design/골목냥_수정설계_2026-10-18.md 1장)
- 관련: D-15

## R-09 사용자와 무관하게 이어지는 고양이 상태
- 사용자 요구: 동네를 바꿔도 같은 동작에서 시작하지 않고, 아무도 없을 때도 상태가 이어져 그 시점 상태를 봄
- 팀장 이해: 세계 시계. 30초 칸 × (고양이 id, 칸 번호) 시드로 행동 결정, 욕구·감정은 시각의 함수, 츄르는 마지막 식사 시각 저장
- 상태: 확인 / 설계됨 (2장)
- 관련: D-04, D-07, P-04

## R-10 회원 전용 교감 지정
- 사용자 요구: 모든 교감이 아니라 지정한 교감(예: 츄르)과 자유게시판만 회원 전용
- 팀장 이해: GATE 설정표, 현재 홍보·츄르만 회원(D-16). R-03을 대체 보완
- 상태: 확인 / 설계됨 (3장)
- 관련: R-03, D-16

## R-11 공유하기

- 팀장 이해: 지역 딥링크(?r=시도코드, 예 ?r=11). X·스레드 intent, 카카오 JS SDK, 인스타는 기기 공유 시트. 카카오·인스타는 배포 후
- 상태: 확인 / 설계됨 (4장)
- 관련: P-01, D-17

## R-12 지금 보고 있는 사람 수

## R-13 인근 지역 놀러가기와 싸움
- 사용자 요구: 이웃 지역 고양이에게 놀러가 높은 확률로 싸우거나 어울리다 1~2분 뒤 귀가. 빈 지역엔 "인근 지역 놀러감" 표지판(행선지 비공개)
- 팀장 이해: 맞닿은 시/도 목록(제주는 놀러가지 않음) + 30분 칸 결정적 외출 일정, 싸움 약 70%
- 상태: 확인 / 설계됨 (7장)
- 관련: R-09, D-18

## R-14 숏츠 영상에서 행동 추가
- 사용자 요구: 유튜브 숏츠의 귀여운 행동을 무료·적은 노력·지속 가능하게 골목냥에 추가
- 팀장 이해: Google AI Studio 저장 프롬프트로 행동 레시피 JSON 생성 → 어드민에 붙여 넣어 미리보기·켜기. 못 하는 동작은 Claude가 추가
- 상태: 확인 / 설계됨 (8장)

## R-15 어드민(테스트) 페이지

- 상태: 확인 / 설계됨 (9장)

## R-16 의견 보내기
- 사용자 요구: 1인 개발 시연이라 부족할 수 있어 방문자 의견을 받고 싶음. 오른쪽 위 버튼 목록에 '의견 보내기', 고양이스러운 팝업, 운영자에게 메일. 칸은 제목/보내는 이(선택)/내용 500자, 용량·글자수 제한, 파일 업로드 금지
- 팀장 이해: 서버 없이 0원 전송(권장 Web3Forms + 선택 Supabase 보관), 이메일은 저장소에 쓰지 않음. 허니팟·쿨다운·링크 차단·텍스트만 표시. 로컬은 모의 어댑터
- 상태: 구현중 (2026-10-19 화면·모의 어댑터·어드민 의견함 구현, 사용자 확인 대기. 실제 Web3Forms 전송·Supabase 보관은 M4) (docs/design/의견함_명소배경_설계.md 1부)
- 관련: D-01, D-12, D-21, P-07, P-16, P-17
