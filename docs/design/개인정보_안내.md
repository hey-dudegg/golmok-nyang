## 0. 전제와 바뀐 점
- 1차(정적 공개): 회원·게시판·의견이 모두 이 브라우저 localStorage(키 앞머리 `golmok:`)에만 있다. 서버 저장 없음.
- D-47·53으로 글꼴·three.js를 직접 호스팅한다. 보안_점검 5-4의 옛 1차 문구(외부 로딩 고지)는 쓰지 않고 1장 문구로 대체했다.
  1차의 외부 요청은 같은 사이트 안의 파일, 방문 통계, 의견 전송뿐이다.
- D-46: 시험 뒤에도 운영하므로 "시험 종료 후 삭제" 대신 "탈퇴·삭제 요청 때 삭제"를 기준으로 쓴다.
- D-48: 운영자 연락 수단은 "의견 보내기"로 적는다(메일 주소 없음).
- D-54: 의견은 config.js에 접근 키가 있을 때만 Web3Forms로 실제 전송한다. 끌 때는 키를 비운다.
- D-55: Cloudflare Web Analytics(쿠키 없는 방문 통계)를 쓴다. D-56: 지우기 버튼은 두지 않는다.
- D-57: 2차 표기 기준(위탁·로그인 제공자·국외 이전·삭제 기한·만 14세 미만). 3장에 반영.
- 1차 화면 문안의 원본은 `src/core/privacy_text.js`이고, 이 문서 1·2장은 그 문안과 같다.

## 1. 1차 짧은 고지
- 긴 것(첫 방문 알림줄): "골목냥은 기록을 이 기기(브라우저)에만 저장하고 서버로 보내지 않아요. [개인정보 안내]"
- 짧은 것(의견 보내기 팝업 맨 아래): "이 기기에만 저장돼요 · [개인정보 안내]"

의견 보내기 팝업에는 전송 상태에 따라 한 줄을 더한다(`PRIVACY_FEEDBACK`).
- 접근 키가 없을 때(모의): "지금은 시험 중이라 의견이 운영자에게 전달되지 않을 수 있어요." (D-54 반영)
- 접근 키가 있을 때(전송): "보낸 의견은 전송 서비스(Web3Forms)를 거쳐 운영자에게 전달돼요. 연락처는 적지 마세요." (D-54 반영)

## 2. 1차 안내 본문
팝업 제목: **개인정보 안내**. 맨 위에 "마지막 수정: YYYY-MM-DD"(코드 상수 `PRIVACY_VERSION`).

**① 무엇을 어디에 저장하나요**
- 골목냥은 이름, 연락처, 생년월일, 위치(GPS)를 묻지 않아요.
- 이웃 등록 정보, 고양이와 친해진 정도, 게시판 글, 이름 투표, 쓰던 의견 같은 기록은
  **지금 쓰는 이 기기의 브라우저(localStorage)에만** 저장돼요.
- 다른 브라우저나 시크릿 창, 다른 사람에게는 보이지 않아요. (게시판 글도 지금은 이 기기에서만 보여요.)

**② 밖으로 보내는 것이 있나요**
- 이 기기에 저장한 기록을 서버나 다른 회사로 보내지 않아요.
- 화면에 필요한 파일(글꼴, 3D 그림 도구, 지도 자료)도 모두 골목냥 사이트 안에서 받아와요. 글꼴 서버 같은 다른 회사 서버에 접속하지 않아요.
- 의견 보내기로 보낸 글만 전송 서비스(Web3Forms)를 거쳐 운영자에게 전달돼요. 그 밖의 글은 보내지 않아요. (D-54 반영)
- 광고, 추적 쿠키, 위치 수집을 쓰지 않아요.

**③ 사이트 접속 기록**
- 골목냥은 Cloudflare라는 호스팅 회사에 올려 두었어요. 페이지를 열면 Cloudflare가 보안과 운영을 위해
  접속한 인터넷 주소(IP), 브라우저 종류, 요청 시각을 기술적으로 처리해요. 운영자는 이것으로 누구인지 찾지 않아요.
- 방문 수를 세기 위해 쿠키 없는 방문 통계(Cloudflare Web Analytics)를 써요. 누구인지 알 수 없는 형태예요. (D-55 반영)

**④ 운영자에게 연락하기**
- 궁금한 점이나 삭제 요청은 화면 위쪽 **"의견 보내기"**로 보내 주세요. 연락처는 적지 않아도 돼요. (D-48)

**⑤ 저장한 기록 지우기**
- 브라우저 설정 → 사이트 데이터(쿠키 및 사이트 데이터) → 골목냥 주소를 찾아 삭제하면 모두 지워져요. 지운 기록은 되살릴 수 없어요.
- 화면 안 지우기 버튼은 두지 않는다(D-56 반영).

**⑥ 바뀌면 알려요**
- 안내가 바뀌면 "마지막 수정" 날짜를 바꾸고, 첫 화면 알림줄을 다시 한 번 보여 드려요.

## 7. 2차 현재 범위 문안(초안, P-44)
- 상태: 초안. 법률 검토 전 문안이다(D-57). 사용자 확인 뒤 developer가 privacy_text.js에 반영한다. 배포 전에는 1·2장의 "이 기기에만 저장" 문구를 그대로 두면 거짓 고지가 되므로 반드시 바꾼다.
- 범위: 익명 세션(D-82), 게시판 읽기만(D-83), 이름 짓기 익명 허용(D-84), 캡쳐 저장(D-85), 의견 Web3Forms(D-54), 방문 통계(D-55), 로그 30일(D-50), 익명 계정 90일 정리·탈퇴 때 사진 먼저 삭제(D-104), 신고·투표 한도(D-106). 로그인(카카오·Google)은 보류라 7-8에 둔다.
- 키 구조: `PRIVACY_VERSION` 날짜를 배포일로 바꾼다. `PRIVACY_NOTICE.long`·`short`를 7-0으로 바꾼다. `PRIVACY_SECTIONS`는 id 6개(store·out·log·contact·erase·change)를 그대로 두고 `lines`만 아래 문장으로 바꾼다. 한 항목 = `lines`의 한 줄.

### 7-0 짧은 고지 (`PRIVACY_NOTICE`)
- long: "골목냥은 익명 계정으로 이름 투표·신고 기록을 서버에 저장해요. 연락처·이메일은 받지 않아요."
- short: "익명 계정으로 서버에 저장돼요"

### 7-1 `store` · ① 무엇을 어디에 저장하나요
- 골목냥은 실명, 연락처, 이메일, 생년월일, 정확한 위치(GPS)를 받지 않아요.
- 익명 계정 번호: 처음 들어오면 기기에 무작위 번호를 만들어 써요. 이름이나 이메일과 묶지 않아요. [확인 필요: 묶임 없음을 실제 구현으로 확인]
- 이름: 이름 짓기에서 직접 정한 이름이에요. 실명은 쓰지 말아 주세요. 익명으로도 이름을 지을 수 있어요.
- 이름 투표·신고 기록: 익명 계정 번호와 함께 저장해요. 하루 한도를 넘지 않도록 기록을 봐요. [확인 필요: 한도 기록의 보관 방식]
- 캡쳐 사진: "캡쳐 저장"을 누르면 사진이 서버에 올라가요.
- 의견: 의견 보내기로 보낸 제목과 본문이에요. 연락처는 적지 마세요.
- 게시판 글은 지금 읽기만 할 수 있어요. 글쓰기 기능은 아직 없어요.
- 접속 중인 사람 수: 지역 코드(시/도)와 익명 계정 번호로 세요. 접속이 끊기면 사라져요. [확인 필요: 서버에 기록이 남는지]
- 고양이와 친해진 정도 같은 진행 기록은 이 기기 브라우저에 남아요. [확인 필요: 2차에서 이 기기에만 남는 항목 목록]
- 보관: 90일 동안 들어오지 않은 익명 계정의 기록(이름·투표·신고)은 지워요. 캡쳐 사진은 그때 또는 탈퇴 때 먼저 지워요. 의견은 90일 보관해요. 오류를 고치기 위한 기록은 최대 30일 보관해요.

### 7-2 `out` · ② 밖으로 보내는 것이 있나요
- 익명 계정 번호, 이름, 투표·신고, 캡쳐 사진, 접속 중 지역 코드는 서버 저장 서비스(Supabase)에 보내요.
- 의견 보내기로 보낸 글은 전송 서비스(Web3Forms)를 거쳐 운영자에게 전달돼요. 그 밖의 글은 보내지 않아요.
- 화면에 필요한 파일(글꼴, 3D 그림 도구, 지도 자료)은 골목냥 사이트 안에서 받아와요.
- 맡긴 곳: Supabase(데이터 저장), Cloudflare(사이트 호스팅·방문 통계), Web3Forms(의견 전달). 이 세 곳은 골목냥을 대신해 기록을 처리해요.
- 국외 이전: Supabase는 서울 지역 서버를 쓴다. [확인 필요: 실제 리전] Cloudflare와 Web3Forms는 국외로 보낼 수 있어요. [확인 필요: 이전 국가명, 전송 방법] 보내는 때는 해당 기능을 쓸 때예요.
- 광고, 광고용 추적 쿠키, 위치 수집은 쓰지 않아요.

### 7-3 `log` · ③ 사이트 접속 기록
- 골목냥은 Cloudflare라는 호스팅 회사에 올려 두었어요. 페이지를 열면 Cloudflare가 보안과 운영을 위해 접속 인터넷 주소(IP), 브라우저 종류, 요청 시각을 처리해요. 운영자는 이것으로 누구인지 찾지 않아요.
- 방문 수는 쿠키 없는 Cloudflare Web Analytics로 세요. 누구인지 알 수 없는 형태예요.
- 오류 기록에는 닉네임, 글 내용, 인터넷 주소를 남기지 않아요. 날마다 바뀌는 암호 값으로만 남겨 누구인지 알 수 없어요. [확인 필요: 로그 실제 구현]
- [예정] 로봇 확인(Cloudflare Turnstile)을 넣으면 이 장에 한 줄을 더하고 이 안내를 바꾼다.

### 7-4 `contact` · ④ 운영자에게 연락하기 (`action: 'feedback'`)
- 궁금한 점이나 삭제 요청은 화면 위쪽 "의견 보내기"로 보내 주세요. 연락처는 적지 않아도 돼요.

### 7-5 `erase` · ⑤ 저장한 기록 지우기
- 브라우저 설정 → 사이트 데이터(쿠키 및 사이트 데이터) → 골목냥 주소를 찾아 삭제하면 이 기기의 기록이 지워져요. 서버에 남은 기록은 이 방법으로 지워지지 않아요.

## 4. 화면 설계와 파일
**4-1. 여는 곳**
| 곳 | 형태 | 시점 |
|---|---|---|
| 첫 방문 알림줄 | 화면 아래 가운데 작은 띠(긴 고지 + [개인정보 안내] + [알겠어요]) | 1차. `store`의 `privacy_seen` ≠ 현재 버전일 때만 |
| 의견 보내기 팝업 맨 아래 | 짧은 고지 한 줄 + 링크 | 1차 |
| 가입 시트(signup) | 3-6 요약 + 링크 + 만 14세 체크 | 2차 |
| `prototype/privacy.html` | 같은 본문의 정적 페이지 | 2차(로그인 설정에 안내 주소가 필요할 수 있음) [사용자 확인] |
- 알림줄은 아래 왼쪽 `#roster`, 아래 오른쪽 `#share`와 겹치지 않게 그 위(bottom 약 76px), 좁은 화면은 전체 폭.
  [알겠어요] 뒤로는 안 뜬다. 항상 떠 있는 바닥글은 두지 않는다(화면이 좁고 단순하게).

**4-2. 형태**: 1차는 **팝업(scrim)**. 별도 페이지는 3D 장면을 다시 불러야 하고, 팝업 틀이 이미 있다.
- `ui/dom.js`의 `openScrim(content, { center: true })`와 `h()` 재사용(닫기·Esc·바깥 누르기·포커스 포함).
- 의견 팝업의 시트 클래스를 재사용, 본문은 스크롤. 글은 모두 `h()`의 text로(innerHTML 금지, A-4).
- ④의 "의견 보내기"는 버튼: 안내를 닫고 `openFeedback(app)`을 연다. 의견 팝업에서 안내를 열어도 쓰던 글은 기존 `draft`에 남는다.

**4-3. 파일** (층: core ← adapters ← state ← render·sim ← ui ← app·main)
| 파일 | 층 | 내용 |
|---|---|---|
| `src/core/privacy_text.js` (새) | core | 문안 데이터만: `PRIVACY_VERSION`, `PRIVACY_NOTICE`({long, short, link, ok}), `PRIVACY_FEEDBACK`({live, mock}), `PRIVACY_SECTIONS`(①~⑥: {id, title, lines[]}). 2차 문안은 2차 때 추가 |
| `src/ui/privacy.js` (새) | ui | `openPrivacy(app, {opener})`→close, `showPrivacyBanner(app)`(본 버전이면 무시). core·adapters/store·ui/dom·ui/feedback import |
| `src/ui/feedback.js` (고침) | ui | 맨 아래 고지 줄 + 링크. privacy.js를 import하면 순환이 되므로 **`app.openPrivacy()` 호출**(main이 붙임) |
| `src/main.js` (고침) | main | `app.openPrivacy = (o) => openPrivacy(app, o)`, 시작 때 `showPrivacyBanner(app)` |
| `prototype/style.css` (고침) | - | 알림줄·본문 스타일 몇 줄 |
| `prototype/privacy.html` (2차, 새) | - | `privacy_text.js`만 import해 본문 출력. three 불러오지 않음 |
- `PRIVACY_FEEDBACK`의 키 `live`는 "전송 상태 문구"의 이름일 뿐 config 항목이 아니다(config의 `live` 항목은 D-54로 없음).
