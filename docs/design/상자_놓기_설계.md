## 0. 요약·전제

- 지역(시/도 16곳, D-05)마다 상자 자리 **1칸**. 비어 있을 때 누가 놓으면 1시간(D-113) 동안 그 지역 전체에 1개만 있고, 그동안 아무도 새로 못 둔다(D-112).
- 놓은 순간 그 지역을 보는 모든 사람에게 실시간으로 나타난다(D-39). 1시간이 지나면 메시지 없이 각자 화면에서 사라진다(만료 시각 판정).
- 판정은 홍보 10초 잠금(2차_연결_실시간 8-2·8-4)과 같은 방식: **DB 함수가 서버 시각 `now()`로 판정**, 이긴 경우에만 DB 안에서 `realtime.send`로 `gn:site`에 내보낸다. 클라이언트는 방송을 못 보낸다.
- 익명 세션만으로 동작(D-82, 익명도 `authenticated`). anon 키만 쓴다(D-11). 새 서버·유료 기능 없음(D-01): Supabase 표 2개·함수 3개 추가.
- 놓은 사람이 적은 **이름을 "○○님의 상자"로 표시**(D-119). 이름은 이름 짓기와 같은 금칙어 검사(`gn_text_check('name')`)·공통 신고(`reports`, 3회 숨김 D-74)를 재사용(D-31·74·75·106). 숨겨지면 "이웃님의 상자". 1인 하루 6회(`per1d`).
- 고양이 쪽은 오브젝트_상호작용_설계의 `PROP_KINDS.crate`(in·top 지점)와 `crateSit` 행동을 그대로 쓰고, "선물 상자" 표시만 얹는다(5장). 자연스러움 규칙(그 설계 4A장, D-120)을 따른다.
- 하지 않는 것: 지역 밖(시군구·동) 단위 상자, 낚싯대 장난감(R-06 나머지), 상자 꾸미기, 놓은 사람 uid·기록 공개(이름 글자만 보임).

## 1. 데이터: 표·RLS·RPC

파일: `supabase/sql/10_box.sql`(01·08·09 뒤. 01의 `is_admin`·`app_config`, 08의 `gn:site` 정책 필요). 표는 RLS 켬·정책 없음 → **함수로만** 읽고 쓴다(홍보와 같음).

### 1-1. 표
| 표 | 열 | 설명 |
|---|---|---|
| `box_state` | `code text primary key` | 시/도 코드. 지역당 1행(최대 16행), 덮어쓰기라 쌓이지 않음 |
| | `holder uuid references auth.users on delete set null` | 놓은 사람(한도 판정용, 밖으로 내보내지 않음) |
| | `placed_at timestamptz not null`, `until timestamptz not null` | 놓은 시각·사라지는 시각(`placed_at + hold_s`) |
| | `seed int not null` | 상자 위치·모양 난수 씨앗(5-1). 모든 화면이 같은 자리에 그림 |
| | `id uuid not null`, `name text not null`, `name_hidden boolean not null default false` | 놓을 때마다 새 `gen_random_uuid()`(신고 대상 `target`). `name`은 1~10자, 필터 통과값. 신고 3회면 `name_hidden=true` |
| `box_log` | `id bigint identity pk, uid uuid not null references auth.users on delete cascade, code text not null, created_at timestamptz not null default now()` | **성공한 놓기만** 1행. 개인 하루 한도 셈. 인덱스 `(uid, created_at)`, `(created_at)` |

- `app_config.limits.box` 초깃값: `{"hold_s":3600,"per1d":6}`(D-119), `app_config.report_hide.box` = 3(D-74 이름과 같은 값). 이미 있는 키가 이김, 08과 같은 방식. 어드민이 값만 조정.
- `reports.kind` check에 `'box'` 추가(`10_box.sql`에서 제약 교체). `report()`·`mod_list`·`mod_restore`는 `create or replace`로 kind='box' 분기만 더한다: 권한 `can_name()`, 숨김 = `box_state.name_hidden=true`(상자 자체는 유지), 복구 = false. 숨김·복구 시 `box` 방송(`name` null/원래 값).
- 지역 코드 검사: 시/도 16곳 코드 배열 상수를 함수 안에 둔다(값은 `core/regions.js`와 같게). 목록 밖이면 `bad_code`.

### 1-2. 함수 (모두 `security definer`, `set search_path = ''`, 거부는 raise 대신 jsonb 반환)
```sql
-- 인터페이스 예시(구현 아님)
box_list() returns jsonb
-- {now: ms, boxes: [{code, id, placed: ms, until: ms, seed, name}]}  until > now() 인 행만.
--   holder는 넣지 않는다. name_hidden이면 name = null. 내 상자면 mine:true(신고 버튼 숨김용, uid 없이 판정)
box_place(p_code text, p_name text) returns jsonb
-- 1 auth.uid() 없음 또는 not can_name() → {ok:false, code:'auth'}
-- 2 p_code가 16곳 밖 → 'bad_code'
-- 2b p_name: trim 후 1~10자 아니면 'bad_name'. gn_text_check('name', p_name) 예외를 잡아 그 코드로 반환(filter_word 등)
-- 3 어드민 아니면: 내 holder 행 중 until > now() 있음 → 'mine_active'(전국에 내 상자 1개만)
--                  box_log 24시간 내 내 성공 수 ≥ per1d → 'rate_limit'
-- 4 insert into box_state (code, holder, placed_at, until, seed, id, name, name_hidden)
--     values (p_code, me, now(), now()+hold_s, 난수, gen_random_uuid(), p_name, false)
--     on conflict (code) do update set ... where box_state.until <= now()  returning *
--   반환 행 없음(아직 남은 상자) → {ok:false, code:'busy', until: ms}
-- 5 box_log insert; realtime.send({code, id, placed, until, seed, name, at}, 'box', 'gn:site', true)
--   send 실패는 함수 안에서 잡고 넘어감(놓기는 유지, 다른 사람은 다음 box_list에서 받음)
-- 6 → {ok:true, now: ms, box:{code, id, placed, until, seed, name, mine:true}}
box_clear(p_code text) returns jsonb   -- is_admin()만. until = now()로 당기고 'box'에 until=now 방송(즉시 사라짐)
```
- 동시에 두 명이 눌러도 4번 한 문장(`on conflict … where`)이 행 잠금으로 처리해 **1명만** 이긴다(별도 `for update` 불필요).
- 검사 순서는 필터(2b)가 한도(3)보다 앞: 금칙어 거부는 하루 6회에 세지 않는다(box_log는 성공만).
- 권한: 세 함수 모두 `authenticated`에만 grant, `anon`·`public` revoke. 표 직접 select·insert·update는 정책 없음으로 거부.
- `realtime.messages` 정책은 08의 `gn_site_read` 그대로(새 정책 없음). 이벤트 이름만 `box` 추가.
- `99_rollback.sql` 앞쪽(역순)에 함수 3개·표 2개 삭제 추가. 탈퇴(07 `member_leave`)는 `box_log` cascade, `box_state.holder`는 null로 남아 상자는 끝까지 보인다.

### 1-3. 정리
- `box_state`: 16행 덮어쓰기 → 정리 불필요. 만료된 행은 남아 있어도 `until`로 걸러진다.
- `box_log`: `daily_cleanup()`(07_misc, D-87 pg_cron 하루 1회)에 `to_regclass('public.box_log')` 가드로 **2일 지난 행 삭제** 4줄 추가. 반환 jsonb에 `box` 개수 추가.
  하루 최대 16곳×24회 = 384행이라 1% 확률 정리(홍보 방식)보다 기존 cron 한 곳에 모으는 쪽이 읽기 쉽다.

## 2. 1시간 만료 판정(서버 시각)

| 어디서 | 기준 | 규칙 |
|---|---|---|
| 서버 `box_place` | `now()` | `until <= now()`인 행만 덮어쓸 수 있다. 이것이 유일한 "놓을 수 있음" 판정 |
| 서버 `box_list` | `now()` | `until > now()`인 행만 돌려준다 |
| 화면 | 서버 시각 보정 | `offset = 응답.now − Date.now()`(box_list·box_place 응답, 방송의 `at`으로 갱신). 지금 서버 시각 ≈ `Date.now() + offset` |

- 화면은 `until ≤ 서버시각추정`이면 상자를 지우고 버튼을 되살린다. 서버에 묻지 않는다(메시지 0).
- 기기 시계가 틀려도 `offset`이 보정한다. 몇 초 어긋나 너무 일찍 누르면 서버가 `busy`+`until`을 돌려주므로 화면은 그 `until`로 다시 맞춘다(버튼 2초 비활성 후 재시도 가능).
- 순수 함수(core, 시험 대상): `boxActive(box, serverNowMs)`, `boxRemainMs(box, serverNowMs)`, `serverNow(offset, localNowMs)`.
- 정해진 수치: 남은 시간 표시는 1분 단위 내림, 1분 미만은 "곧 사라져요".

## 3. 실시간 전달·연결 실패

- 채널은 기존 `gn:site` 하나(2차_연결_실시간 8-1). 지역별 채널을 만들지 않는다. 방송 `box`는 모든 접속자가 받고 **`code`가 지금 보는 지역일 때만** 그린다.
- 페이로드 `{code, id, placed, until, seed, name, at}`: uid 없음. `name`은 표시용 글자 또는 null(숨김). `at`은 서버 시각(ms). 같은 `id`의 다음 방송(숨김·복구)은 이름만 바꾼다.
- 받을 때 검사: `code`가 16곳 안, `until > placed`, `until − placed ≤ 2시간`, `seed` 정수, `id` uuid 모양, `name`은 null 또는 1~10자 `core/name_rules` 글자. 아니면 버린다.
- 이름은 화면에 **textContent로만** 넣는다(innerHTML 금지). 장면 3D 글자는 만들지 않는다(패널 문구만).
- `box_list()`를 부르는 때: 첫 연결(`SUBSCRIBED`) 직후, 지역 바꿀 때, 재연결 직후, 탭이 다시 보일 때(60초 숨김 뒤 재가입, 8-5). 주기적으로 묻지 않는다.
- 어댑터(`adapters/supabase.js`, LocalMock도 같은 모양):
```js
// 인터페이스 예시. Caps에 box 추가: { user, db, room, lock, box }
// box: { list() → Promise<{ now, boxes }>, place(code, name) → Promise<{ now, box }>, clear(code) → Promise<void> }
//   place 거부는 Error(code) 던짐: busy(err.until 포함)·mine_active·rate_limit·bad_code·bad_name·filter_*·auth·network
//   신고는 이름 신고가 쓰는 기존 어댑터 신고 호출에 kind 'box', target id만 넘긴다(새 메서드 없음)
// room.on(f): 기존 'promo'에 더해 'box' 수신 → f('box', payload)
```
- LocalMock: localStorage 한 키(`gn.box`)에 지역별 `{placed, until, seed}`. `now`는 `Date.now()`. 로컬 개발·시험용(같은 브라우저 탭끼리만 보임).
- 연결 실패(`room.live=false` 또는 Caps.box 없음): 놓기 버튼 `disabled` + title "지금은 상자를 놓을 수 없어요". 이미 받은 상자는 `until`까지 그대로 보인다.

## 4. 화면 흐름: 놓기 버튼·남은 시간

위치: 교감·함께 패널(홍보 버튼 옆, `ui/together.js` 근처). 새 파일 `ui/box.js`가 버튼·문구만 맡는다.

| 상태 | 버튼 | 장면·안내 |
|---|---|---|
| 비어 있음 | "상자 놓아 주기" 활성 | — |
| 이름 입력 | 버튼 아래 한 줄 입력칸(10자, 지난번 이름 미리 채움 `localStorage gn.box.name`) + "놓기" | 앱 쪽 `core/name_rules`로 글자 검사 후 전송(빠른 안내), 최종 판정은 서버 |
| 누름(응답 대기) | 비활성, "놓는 중…" | 최대 10초, 넘으면 network 문구 |
| 내가 놓음(ok) | 비활성, "○○님의 상자 · 58분 남음" | 안내 3초 "상자를 놓았어요! 1시간 뒤에 사라져요". 상자 나타남. 신고 버튼 없음 |
| 남이 놓음(방송) | 비활성, "○○님의 상자 · 42분 남음" + 작은 "신고" | 안내 3초 "○○님이 상자를 놓아 줬어요". 상자 나타남 |
| 이름 숨김 | "이웃님의 상자 · 남은 시간" | 신고 버튼 없음. 상자는 그대로 |
| 남은 1분 미만 | "○○님의 상자 · 곧 사라져요" | — |
| 만료 | 다시 활성 | 상자 사라짐(고양이가 안에 있으면 5-3 규칙) |
| 연결 없음 | 비활성 + title | 3장 |

- 남은 시간 글자는 1분마다 갱신(`setInterval` 60초, 탭 숨김 중 멈춤). 프레임마다 계산하지 않는다.
- 확인 창은 두지 않는다(이름 입력 후 "놓기" 한 번). 입력칸 안내 "모두에게 '○○님의 상자'로 보여요. 실명·연락처는 적지 마세요".
- 오류 문구: busy "방금 다른 이웃이 상자를 놓았어요", mine_active "이미 다른 동네에 놓은 상자가 있어요",
  rate_limit "상자는 하루에 6번까지 놓을 수 있어요", bad_name·filter_* "쓸 수 없는 이름이에요"(이름 짓기 문구 재사용),
  bad_code·auth "지금은 상자를 놓을 수 없어요", network "연결이 끊겨 상자를 놓지 못했어요".
- 신고: 확인 창 1회 → 신고 호출 → "신고했어요"(횟수는 알리지 않음, D-31). 같은 상자 다시 신고는 조용히 무시.
- 접근성: 버튼 `aria-live="polite"` 영역에 안내 문구. 상자는 장면 그림이라 별도 낭독 없음.
- 어드민 화면(오브젝트 구역, 오브젝트_상호작용_설계 7장): "선물 상자 놓기·치우기" 시험 버튼. Supabase 모드면 `box.clear`, LocalMock이면 로컬 값만.

## 5. 고양이 행동 연결

### 5-1. 상자 자리 (순수, `core/props.js`에 함수 1개 추가)
- `giftSpot({ code, seed, obstacles, props }) → { kind:'crate', look:'gift', x, z, rot, seed } | null`
- `makeRng('gift:' + code + ':' + seed)`로 정하고, 규칙은 `layoutFor`(2.3)와 같다: 기존 장애물·배치 오브젝트와 겹침 검사 20번, 통로 ≥ 0.5m,
  접근점은 `BOUNDS` 안. 추가로 **카메라 기본 화면 x −1.2~1.2, 앞쪽 z 0~0.8**(잘 보이는 곳). 실패하면 `null` → 상자는 패널 문구로만 존재(버튼 상태는 같음).
- 같은 `code·seed`면 모든 화면이 같은 자리(결정적). 서버는 `seed`만 정한다.

### 5-2. 모양
- `PROP_KINDS.crate` 그대로(0.55×0.45×0.28, 지점 `in`·`top`). `look:'gift'`면 종이 갈색 + 위로 벌어진 날개 4장 + 테이프 줄(얇은 상자 1개) → 장면에 원래 있던 상자와 구분.
- 나타날 때 0.3초 아래에서 위로 커지기, 사라질 때 0.3초 줄어들기. `render/props.js`의 crate 그리기에 `look` 분기만 추가, 해제 시 형상·재질 dispose(누수 0).

### 5-3. 행동
| 행동 | 조건 | 흐름 | 점수 |
|---|---|---|---|
| crateSit (O2, 기존) | gift 상자의 `in` 비어 있음 | 들어가기 → `sit`/`loaf`(귀·머리만) | 기존 식 × **gift 배수 2.5**(처음 15분은 4) |
| giftPeek (신규, 작은 추가) | 위와 같음 | 들어가기 → `peek`(빼꼼) 4~10초 → `sit` 또는 나옴 | `avail * (0.2 + curious*0.6 + (1-bold)*0.4)` |
| giftSniff (신규) | 상자 놓인 뒤 첫 결정 | 접근 → 냄새 맡기(기존 sniff 자세 재사용) 3초 → 위 둘 중 하나 또는 떠남 | 처음 15분만, 고양이당 1회 |

- 감정 편향(`EMO_BIAS`): giftPeek curious +0.6·playful +0.3, giftSniff curious +0.8. 극성 짝짓기(D-30)는 오브젝트 설계 3장 규칙 그대로.
- 자리 수: `in` cap 1 → 여러 고양이 중 한 마리만 들어간다. 나머지는 `top`(가장자리 앉기) 또는 sniff.
- 새끼 높이 제한·숨은 상태 쓰다듬기(peek 반응·끌어내지 않음)는 오브젝트 설계 O2-2 규칙 그대로.
- **결정성**(D-19): 상자 있음 = `placed ≤ t_결정 < until`. 결정 시점 기준이라 늦게 들어온 사람·빨리 감기도 같은 결과.
  행동 선택 입력에 `world.gift = { placed, until, spot } | null`을 넣는다(sim이 직접 시계·네트워크를 보지 않음).
- 만료 순간 고양이가 안에 있으면(D-120, 오브젝트 설계 4A-1): 고양이가 낮은 걸음으로 **먼저 나온 뒤** 상자를 0.3초 줄여 지운다(최대 2초 지연). 나오는 끝에 slot `release`. 상자에 들어간 채 사라지거나 위치가 튀지 않는다.
- 상자 안 고양이 쓰다듬기·츄르는 그 자리 반응(4A-2). 재진입 쿨다운·사슬 반복 금지도 같은 규칙.
- 기능 스위치: 개발 중 오브젝트 스위치(O1-4)가 꺼져 있으면 상자는 보이되 행동 점수 0(겉모습만). **출시 때 켬**(D-120).

## 6. 남용 방지

| 위험 | 대책 |
|---|---|
| 한 사람이 16곳 독점 | `mine_active`: 전국에 내 상자 1개까지(만료돼야 다음) |
| 만료 직후 같은 사람 연속 독점 | `per1d` 6회. 1시간 유지라 하루 6시간 이상 혼자 잡지 못함 |
| 다계정(익명) | 익명 가입 Turnstile(D-106)로 비용을 올림. 계정이 늘어도 지역당 1개·1시간이라 피해는 "상자가 계속 있음" 정도 |
| 연타·도배 호출 | 실패는 기록하지 않고 DB 비용만 듦(함수 1회). 버튼은 응답 전 비활성, 실패 뒤 2초 비활성 |
| 위조 방송 | 클라이언트 broadcast insert 정책 없음(08). 받는 쪽 검사(3장) |
| 부적절한 이름 | 서버 `gn_text_check('name')`(금칙어·URL·연락처·글자 제한, D-31) + 신고 3회 이름 숨김(D-74·75). 어드민 `mod_list`·`mod_restore`로 검토, `box_clear`로 상자째 치우기 |
| 신고 남용(익명 여러 브라우저) | 이름 신고와 같은 수용 범위(필터 3-4): 숨김은 이름만, 상자·시간은 그대로. 남용 시 `report_hide.box` 값만 올림 |
| 이름으로 연락처 퍼뜨리기 | 10자 제한·글자 제한(한글·영문·숫자·띄어쓰기)·연락처 정규식. 1시간 뒤 사라짐 |
| 개인정보 | holder·uid는 표 안에만, 함수 응답·방송에 넣지 않음(`mine`은 서버 판정 불린). 이름은 표시용으로 상자 행에만, 다음 놓기가 덮어씀. `box_log`엔 이름 없음. 탈퇴 시 log 삭제·holder null |

- 한도 수치는 `app_config.limits.box`에서 어드민이 바꾼다(D-106 방식). 1인 하루 6회(D-119). 시간당 한도는 1시간 유지·`mine_active`로 이미 1회라 따로 두지 않는다.
- 익명은 브라우저를 지우면 새 uid라 하루 6회가 초기화된다: 익명 가입 Turnstile·IP당 한도(D-106)로 보완(이름 짓기와 같은 수용).
