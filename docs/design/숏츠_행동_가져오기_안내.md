# 숏츠에서 고양이 행동 가져오기 (동준님용 안내)

> 유튜브 숏츠에서 본 귀여운 고양이 행동을 골목냥 고양이가 따라 하게 만드는 방법입니다.
> 비용 0원, 영상 하나당 1~2분. 처음 한 번만 준비(약 5분)가 필요합니다.
> 어드민 "행동 레시피" 칸은 구현 4단계에서 생깁니다. 그 전에는 5번 "어드민이 아직 없을 때"를 따라 주세요.

## 1. 처음 한 번만: 프롬프트 저장하기

1. 브라우저에서 **https://aistudio.google.com** 에 들어가 Google 계정으로 로그인합니다(무료).
2. 새 채팅(Chat)을 엽니다. 모델은 목록에서 가장 위의 Flash 모델이면 됩니다.
3. 오른쪽 "System instructions(시스템 안내)" 칸에 아래 **프롬프트 전체**를 붙여 넣습니다.
4. 위쪽 저장 버튼으로 "골목냥 행동 레시피"라는 이름으로 저장합니다. 다음부터는 왼쪽 목록에서 이 이름을 눌러 바로 씁니다.

```
너는 고양이 행동 분석가다. 사용자가 보낸 영상 속 고양이의 행동 하나를 골라
아래 JSON 형식으로만 답하라. 설명 문장은 쓰지 마라.
행동이 여러 개면 가장 귀엽고 눈에 띄는 것 하나만 고른다.

{
  "name": "행동 이름(한국어, 짧게, 24자 이내)",
  "when": { "emotion": ["감정"], "need": "욕구 상황", "place": "장소(한국어 16자 이내)" },
  "duration_s": 숫자(1~40),
  "steps": [ { "t": 시작초, "pose": "", "move": "", "ears": "", "eyes": "", "pupil": "", "tail": "", "head": "", "sound": "" } ],
  "unknown_moves": ["목록에 없는 몸동작을 한국어로 묘사"]
}

단계(steps)는 24개 이하, t는 0부터 duration_s 안에서 커지는 순서로 쓴다.
각 칸에는 아래 단어만 쓴다. 해당 없으면 칸을 빼라.
- pose: sit, stand, loaf, lie_side, lie_belly, crouch, stretch, arch, lean_side, roll
- move: stay, walk, trot, run, jump_up, jump_down, pounce, to:box, to:wall, to:sunny, to:hide, to:you
- ears: forward, side, back_flat, swivel, one_back
- eyes: open, half_closed, slow_blink, wide, closed
- pupil: small, normal, large
- tail: up, up_hook, low, puff, wrap, flick, lash
- head: tilt_left, tilt_right, rub_left, rub_right, look_up, look_down
- sound: none, meow, trill, purr, hiss, yowl
- emotion: 편안, 호기심, 신남, 애정, 경계, 두려움, 짜증, 졸림
- need: 에너지 높음/낮음, 배고픔 높음, 지루함 높음, 안심 높음/낮음

목록 단어로 표현할 수 없는 몸동작(예: 뒷발로 서서 앞발 모으기)은 steps에 넣지 말고
unknown_moves에 한국어로 자세히 적어라.
```

> 한도: 이름 24자, 장소 16자, 길이 1~40초, 단계 24개, 못 하는 동작(unknown_moves) 8개(각 80자), 입력 전체 6000자. 저장은 30개, 동시에 켜는 것은 10개까지입니다. 한도를 넘으면 어드민 검사에서 오류로 알려 줍니다.

> 단어 목록은 골목냥이 할 줄 아는 동작이 늘면 바뀝니다. 바뀌면 어드민 "행동 레시피" 화면에 최신 프롬프트 복사 버튼이 생깁니다.

## 2. 영상마다: 레시피 받기 (약 1분)

1. 유튜브 앱이나 사이트에서 숏츠의 **공유 → 링크 복사**를 누릅니다.
2. AI Studio에서 저장한 "골목냥 행동 레시피"를 엽니다.
3. 입력칸에 링크를 붙여 넣고 실행합니다. (화면의 + 버튼에 "YouTube video" 항목이 있으면 그걸로 넣어도 됩니다.)
4. 나온 JSON(중괄호 `{`부터 `}`까지)을 복사합니다.

## 3. 골목냥에 넣기 (약 1분)

1. 골목냥 주소 뒤에 `?admin`을 붙여 어드민을 엽니다.
2. "행동 레시피" 칸에 복사한 JSON을 붙여 넣고 **미리보기**를 누릅니다. 고양이가 바로 따라 합니다.
3. 마음에 들면 **켜기**. 이제 그 행동이 고양이의 일정 후보에 들어가, 감정·상황이 맞을 때 가끔 나옵니다.
4. 마음에 안 들면 그냥 두거나 **삭제**. 켜지 않은 레시피는 실제 고양이에게 나오지 않습니다.

## 4. "새 동작 필요"가 뜨면

- 레시피의 `unknown_moves`에 내용이 있으면 어드민이 "새 동작 필요"로 표시합니다. 목록에 있는 부분만 미리보기로 움직입니다.
- 그 레시피 JSON을 **로컬 Claude Code(저장소 폴더에서 `claude`)에 붙여 넣고 "새 동작 추가해 줘"** 라고 보내 주세요. Claude가 고양이 뼈대 동작을 새로 만들고 단어 목록에 추가합니다.

## 5. 어드민이 아직 없을 때 (구현 4단계 전)

- 2번까지 한 다음, 받은 JSON을 로컬 Claude Code에 붙여 넣고 "이 행동 넣어 줘"라고 보내 주세요. Claude가 직접 넣습니다.

## 6. 잘 안 될 때

| 증상 | 해결 |
|---|---|
| "영상을 볼 수 없다"고 함 | 공개 영상만 됩니다(일부 공개·비공개 불가). 다른 숏츠로 시도하거나, 영상을 저장해 AI Studio에 파일로 올려 주세요 |
| AI Studio에서 링크가 안 먹힘 | 같은 프롬프트와 링크를 **https://gemini.google.com** 에 함께 붙여 넣어 보세요 |
| JSON이 아니라 설명 글이 나옴 | "JSON만 다시"라고 한 번 더 보내면 됩니다 |
| 하루에 너무 많이 돌렸다고 함 | 무료 한도는 하루 영상 8시간 분량입니다. 다음 날 다시 하면 됩니다 |
| Gemini 무료 정책이 바뀜 | 같은 프롬프트를 다른 무료 영상 분석 AI에 쓰면 됩니다. 레시피 형식은 골목냥 쪽에 있어서 그대로 씁니다 |

참고: [Gemini API 영상 이해 문서](https://ai.google.dev/gemini-api/docs/video-understanding) (공개 유튜브 링크 지원, 무료 등급 하루 8시간, 미리보기 기능이라 정책 변동 가능)
