## 1. 공통 사실(코드에서 확인)
- 회전 부호: hips·chest는 'YXZ' X축 회전. **음수 = 앞(머리)쪽 들림**(sit hp −0.62·cp −0.42). 다리는 몸에 붙어 같이 돌므로
  몸을 세우면(hp 음수) 다리가 앞(배 밑)으로 쏠린다 → 다리 세계각 ≈ hp + hls로 보고 보정한다.
- 좌우: hipL·shL이 +x쪽(cat_model 158줄 sx=1). hsp·fsp는 좌우 공용 한 키(L은 −, R은 +로 대칭 적용)라 한쪽만 벌릴 수 없다.
- plant 방식(cat_model update): 'all' 네 발 평균, 'front' 앞발, **'hind' 뒷발 최저**, 'min' 네 발 중 최저, **'sit' 앞발 + solveSit(엉덩이를 앞발 높이까지 hp 이분 탐색)**, 'none' 최저 정점.
  - 'sit'은 뒷발을 보지 않는다 → **한 뒷다리를 들어도 접지가 흔들리지 않는다**. 'all'은 든 발이 평균을 끌어올려 몸이 가라앉으므로 쓰지 않는다.
  - 안전망: 어느 피부 정점이든 바닥(−GROUND_SINK) 아래면 몸 전체를 올림(extra = hFinal − hOff). 걸리면 디딘 발이 뜬다 → 측정 대상.
- 전환(pose_plan): bodyDelta = BODY_KEYS(hp hy hr cp cy cr) 최대 차. ≤ ROT_LIMIT 0.52면 1단계, 넘으면 ceil(d/0.52)단계 섞기.
  LOW(plant 'none')가 끼지 않으면 접기(TUCK) 없이 모든 키를 섞는다. 이번 자세는 모두 비LOW라 **새 분기 불필요**.
- 오버레이 a.ov는 자세 값에 **더해진다**(groom의 hdp sin, archSide puff 보탬과 같음). 반복 동작은 STEP.track(…, {period}) 또는 fx의 sin.
- 긁기 대상 슬롯 확인: 담은 top0·top1('on', 위) + behind('beside', action null, 담 뒤 −z 0.3m 그늘), 상자는 'in'뿐.
  **벽면을 마주 보는 슬롯이 없다.** 새 슬롯을 만들면 PROP_ACTION_KEYS·점유(cap)·NEEDS까지 손대야 한다.
  → headBump·cheekRub처럼 explore_actions의 nearProp + edgePoint(바깥 둘레 점)를 쓴다(4장, 대안은 7장).

## 2. 뒷다리 그루밍 groomHind (M24-4a 자세 / M24-5a 행동)
### 2.1 자세 groomHindL (render/poses.js, sit 바탕. R은 sg=−1로 좌우 키·부호 뒤집기)
| 키 | 시작값(L) | 이유 |
|---|---|---|
| plant | 'sit'(상속) | 앞발 + 엉덩이 깔기. 든 뒷다리는 접지 계산에 안 들어감(1장) |
| hr / cy | +0.25·sg / +0.20·sg | 든 다리 반대 엉덩이로 기대고 가슴을 다리 쪽으로. sit 대비 bodyDelta 0.25 → 1단계 |
| hls / hlk | −2.0 / +0.2 | 든 다리: 앞·위로 곧게(세계각 ≈ −0.62−2.0 ≈ 150°). R은 hrs/hrk에 |
| hrs / hrk | sit 그대로(−0.9 / −1.4) | 받치는 다리는 접은 채 |
| hsp | 0.45 | 공용 키. 든 다리가 가슴을 뚫지 않게 벌림(받치는 다리도 같이 벌어짐, 엉덩이로 앉아 안 보임) |
| fls·frs / fsp | 0.95·1.10 / 0.12 | 앞발로 버팀(받치는 쪽을 조금 더 뒤로) |
| np / ny / hdp / hdr | 0.85 / 0.5·sg / 0.6 / 0.2·sg | 머리를 든 다리 안쪽 허벅지로. ny 부호는 front 촬영에서 다리 쪽으로 도는지 확인 |
| tb / tw / eye / mouth | 0.2 / 0.02 / 0.3 / 0.1 | 꼬리 바닥에 낮게, 눈 반쯤 |
- 값은 시작값이다. `--poses sit,groomHindL --measure`, `--poses stand,groomHindL --measure`로 보고 ±0.15 안에서 조정.
- 접지·안전망: hr 기울임으로 엉덩이 한쪽이 내려가도 solveSit이 다시 맞춘다. 든 발은 높아 안전망과 무관.
  **위험 지점은 전환 중간**: sit→groomHindL 1단계 섞기에서 무릎이 −1.4→+0.2로 펴지며 발끝이 바닥을 긁고 지나갈 수 있다(안전망 들썩).
  측정 ④(전환 중 extra 최대)가 0.005 넘으면 행동에서 중간 자세(sit + `{hls:−1.6, hlk:−1.4}` 0.3초)를 한 단계 넣는다(엔진 변경 없음).
- 전환 경로(D-129): sit→groomHind 1단계(d 0.25), stand→groomHind 2단계(d 0.62, 섞기·접기 없음). 행동은 항상 sit을 먼저 거친다.

## 3. 귀 긁기 earScratch (M24-4a 자세 / M24-5a 행동)
### 3.1 자세 earScratchL (sit 바탕, R은 sg=−1)
| 키 | 시작값(L) | 이유 |

| plant | 'sit'(상속) | 2장과 같은 이유 |
| cp / hr / cy | −0.30 / +0.15·sg / +0.35·sg | 몸을 긁는 쪽으로 말아 엉덩이와 머리 거리를 줄임. sit 대비 d 0.35 → 1단계 |
| hls / hlk | −2.3 / −1.5 | 허벅지를 옆구리 따라 앞으로, 정강이를 접어 발끝이 귀 쪽을 향함 |
| hsp | 0.5 | 발이 어깨 바깥으로 지나가게 |
| np / ny / hdp / hdr | 0.55 / 0.9·sg / 0.35 / 0.55·sg | 머리를 다리 쪽으로 돌리고 기울여 귀를 발 쪽으로 내림 |

## 4. 긁기 scratch (M24-4a 자세 / M24-5b 행동)
### 4.1 자세 scratch (담: 서서 앞발을 높이 뻗음)
| 키 | 시작값 | 이유 |
|---|---|---|
| plant | 'hind' | 뒷발만 바닥, 앞발은 벽에 댐(바닥 기준 아님) |

### 4.2 자세 scratchLow (상자: 높이 0.28이라 덜 세움)
scratch 바탕에 `hp −0.50, cp −0.15, hls·hrs +0.30, fls·frs −0.55`. stand 대비 d 0.50 → 1단계. 앞발 끝 높이 목표 0.12~0.25m(상자 벽 0.28 아래).
- 접지·안전망: 'hind'라 뒷발 최저가 바닥. **몸을 세우면 엉덩이 뒤끝·꼬리 뿌리가 뒷발보다 낮아질 수 있다** → 안전망이 몸을 올려 뒷발이 뜬다.
  측정 ②(extra)가 0이 아니면 tb를 +0.2, 그래도면 hp를 +0.1(덜 세움)씩 조정.
- 전환 경로(D-129): stand→scratch 2단계(섞기, 접기 없음, 중간 단계도 plant 'hind'), sit→scratch d 0.23 1단계(plant 'sit'→'hind' 바뀜은 hOff 감쇠 14/s로 이어짐),
  scratch→stretch(plant 'min', d 1.21) 3단계, scratch→sit d 0.23. 새 분기 불필요. 섞기 중간에 앞발이 바닥을 뚫는지 측정 ③.

### 4.3 행동 scratch (core/explore_actions.js, 슬롯 대신 바깥 둘레 점)
```js
const SCRATCH_KINDS = new Set(['lowwall', 'crate']);
const nearScratch = (a) => /* liveProps() 중 SCRATCH_KINDS·look !== 'gift'·2.5m 안에서 가장 가까운 것 */;
scratch: { label: '담·상자 긁기', score: (a) => (nearScratch(a) ? 0.05 + a.p.energy * 0.03 + a.p.bold * 0.02 : 0), steps: (a, r) => [...] }
// clock.js: EMO_BIAS scratch: { playful: 0.3, grumpy: 0.4 } (PASSIVE 아님). shoot_action NEEDS에 scratch: 'wall'
```
- 서는 자리 p: 담이면 **카메라 쪽 면(로컬 +z)** 고정(담 배치 rot 0, 뒷면은 담에 가려 안 보임), 상자는 `edgePoint(o, a, m, false)`(가까운 변).
  간격 m = SCRATCH_GAP(시작 0.14 + 0.06·a.scale, 측정 ④로 조정). 바라볼 방향은 q = 같은 변의 m=0 점, `STEP.face(atan2(q.x−p.x, q.z−p.z))`.
- 담 +z 면 점: 로컬 (clamp(lx, −hx+0.15, hx−0.15), hz+m)을 월드로(edgePoint와 같은 회전식). 도우미 `facePoint(o, a, m)` 1개로 두 경우를 묶는다.

| # | STEP | 시간 | 내용 |
|---|---|---|---|
| 1 | `STEP.walk(p.x, p.z, 0.8)`, `STEP.face(…)`, `STEP.pose('stand', 0.4)` | ~0.4s+걷기 | 면 앞에 서서 마주봄 |
| 2 | `STEP.track(o.kind==='crate' ? 'scratchLow' : 'scratch', r.range(2.5, 4.5), null, strokes, { period: 0.36 })` | 2.5~4.5s | strokes: `fls [[0,0],[0.18,0.25],[0.36,0]]`, `frs [[0,0.25],[0.18,0],[0.36,0.25]]`, `hr [[0,0.03],[0.18,−0.03],[0.36,0.03]]` (앞발 번갈아 내려 긋기, 엉덩이 살짝 흔듦) |
| 3 | (40%) `STEP.pose('stretch', 2.0)` | 2.0s | 긁고 기지개(자연스러운 이어짐) |
| 4 | `STEP.pose('stand', 0.5)`, `STEP.pose('sit', 1.5)` | 2.0s | 끝 |

- 새끼: 같은 자세(체형 비율로 작아짐). 담 0.80은 못 오르지만 면 긁기는 바닥에서 하므로 제한 없음.

- 도구에 없는 값(③ 발끝–귀 거리, ④ 앞발–벽면 거리, extra)은 `--measure` 출력에 줄을 보탠다. **tests/lib는 M24-1 작업 중이라 그 완료 뒤에** M24-4b로 한다.
- 촬영 예: `--action scratch --props wall@0,-0.6 --cat 0,-0.1 --measure`, `--action scratch --props crate@0,-0.6 …`.
