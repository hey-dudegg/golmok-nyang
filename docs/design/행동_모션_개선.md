## 1. 공통

### 1.1 엔진 제약 (뼈대 22개, cat_model.js buildRig)
| 부위 | 관절·자세 키 | 축 |
|---|---|---|
| 척추 | hips(hp·hy·hr) → chest(cp·cy·cr, hips 자식) | **2마디**. 굽힘·비틀기·옆굽힘 모두 2점으로만 |
| 목·머리 | neck(np, ny×0.4) → head(hdp, hdy+ny×0.6, hdr) | 목은 **roll 없음**. 머리만 roll(hdr) |
| 앞다리 | shL/R(fls·frs pitch, fsp 벌림) → elL/R(fle·fre) | 어깨·팔꿈치 2관절. **손목·발가락 없음** |
| 뒷다리 | hipL/R(hls·hrs, hsp) → knL/R(hlk·hrk) | 엉덩이·무릎 2관절. 발목 없음 |
| 꼬리 | t0(tb pitch, ts yaw) + t1~t7(tc·tcs, 7마디 **같은 값**) | **8마디**. 마디별 값 따로 못 줌, roll 없음. tw·twf는 yaw 파동만 |
| 기타 | eL·eR(귀 납작), eye, pupil, mouth, puff, lift(root y) | 코·수염 없음 |

부호(코드에서 확인): hp·cp·np·hdp +는 앞으로 숙임(아래), −는 들기. hiss의 등 굽힘 = hp −, cp +.
yaw +는 앞(+z)을 +x 쪽으로 돈다. 꼬리는 뒤(−z)를 향하므로 **ts·tcs +는 꼬리 끝을 −x로** 보낸다.

접지(view.update): plant `all`=네 발 평균, `front`·`sit`=앞발 최저, `hind`, `min`=네 발 최저, `none`=피부 최저점.
**모든 모드에서 h는 바닥 맞춤에 상쇄된다.** 실제 높이는 plant와 관절값이 정한다. 표의 h는 기존 값 유지라는 뜻이다.
안전망: 어느 정점이든 바닥 아래면 몸 전체를 올린다. 그래서 **머리·꼬리가 몸보다 낮으면 몸이 뜬다**(belly 원인).
`sit` 모드는 solveSit이 hp를 다시 계산한다. 앉은 자세의 등 굽힘은 hp 대신 cp·np로 준다.
보간: 모든 키를 같은 속도(4.2, h 5, eye·mouth 10)로 damp한다. 0.25초보다 빠른 동작은 ov로만 낼 수 있다(ov는 보간 없이 더해짐).

### 1.3 공유 엔진 변경 (M19-2에서 먼저)
**E1 가라앉기 전환 `sink`** (core/pose_plan.js)
- 자세 객체에 `sink: true`가 있으면 planPose는 TUCK 단계를 넣지 않는다.
- 단계 수 n = max(2, ceil(d / ROT_LIMIT)), hold = max(STAGE_MIN, 기존 식).
- 중간 단계 k: 모든 숫자 키를 mix(from, to, k/n)로 섞는다(다리 포함). plant = `'min'`(발이 땅을 디딘 채 내려감).
- 예외: from이 앉음(`plant === 'sit'`)이면 뒷다리 4키(hls·hlk·hrs·hrk)는 첫 단계부터 to 값(이미 접힌 다리를 펴지 않음).
- 마지막 단계는 to 그대로(plant `none`). 역방향(일어나기)은 이번 범위 밖.

**E2 키프레임 오버레이 `STEP.track`** (core/behavior.js STEP)
```js
// tracks: { 키: [[초, 값], ...] } 구간 smoothstep 보간. period가 있으면 t % period로 반복
STEP.track(name, dur, extra, tracks, { period, fx })  // 매 tick a.ov[key] = 값
```
- 표의 ov 열을 그대로 옮겨 적을 수 있게 한다. 난수가 필요하면 steps()에서 r로 배열을 만들어 넘긴다.
- 기존 STEP.pose와 같이 start에서 setPose(name, extra), tick에서 t 누적. 순수 계산이라 node 시험 가능.

**E3 from.plant 바로잡기** (core/pose_plan.js PoseQueue.set)
- 지금 P.plant는 처음 'sit'에서 바뀌지 않는다(blendPose는 PARAM_KEYS만, snap만 갱신). LOW(from) 판정이 틀린다.
- set에서 `planPose({ ...this.P, plant: this.goal.plant }, to)`로 직전 목표의 plant를 넘긴다.
- 영향: 이미 누운 상태에서 다른 누운 자세로 갈 때 불필요한 TUCK이 사라진다. 기준값 시험이 바뀔 수 있다(15장 Q1).

### 1.4 판정 촬영 공통
- tests/lib/capture.js의 fixCamera·hidePanels·shoot를 쓴다. 컷 시각은 행동 첫 STEP 시작 기준 초.
- 수치 판정은 view.minPart(부위별 최저 y)와 hFinal을 쓴다. 성체(growth 1)·아기(0.3) 2체형에서 확인.

## 2. 식빵 loaf (M19-2)
특징: ① 다리를 굽히며 몸이 같이 낮아진다 ② 앞발이 가슴 밑으로 사라진다 ③ 등이 수평, 눈 반감김.
원인: 전환 순서(1.2). TUCK 단계가 몸보다 먼저 다리를 몸쪽으로 당긴다.

| 시각 | 자세 키 (from=stand 기준) | plant | h | ov |
|---|---|---|---|---|
| 0.0 | stand 또는 sit 현재값 | 이전 | 이전 | 없음 |
| 0.5 | E1 중간: hp 0.01, cp −0.03, np 0.03, hdp 0.03, fls 0.75, fle −1.25, hls −0.92, hlk 1.6 | min | mix | 없음 |
| 1.1 | loaf 목표(현 값 그대로) | none | 기존 | 없음 |
| 1.1~ | 유지. slowBlink 기존대로 | none | 기존 | cp = 0.015·sin(t·1.6) (숨쉬기) |

- from=sit이면 0.5 단계에서 hp −0.30, cp −0.24, fls 1.27, fle −1.25, 뒷다리는 loaf 값(E1 예외).
- 엔진: E1. poses.js loaf에 `sink: true` 추가. nap·sideNap·belly·flee가 거치는 loaf도 함께 좋아진다.
- 완료 조건: 전환 중 엉덩이 최저(minPart hips)가 0.005 이상 다시 올라가지 않음(30fps 표본). 앞발 최저가 0.5초까지 바닥 ±0.004.

| 컷 | 시각 | 보여야 할 것 |
|---|---|---|
| L1 | 0.0 | 시작 자세(서기) |
| L2 | 0.5 | 무릎·팔꿈치가 반쯤 굽고 몸통이 반쯤 내려옴. 발은 바닥 |
| L3 | 0.9 | 가슴이 거의 바닥, 앞발이 가슴 밑으로 들어가는 중 |
| L4 | 2.0 | 완성 식빵. 앞발 안 보임, 등 수평 |

## 3. 발라당 belly (M19-2)
특징: ① 등(어깨~허리)이 바닥에 닿고 배가 하늘로 ② 앞발은 가슴 위에서 구부림, 뒷발은 벌어짐 ③ 몸을 좌우로 뒹군다.
원인: 자세값(1.2). 뒤집힌 몸에서 목·머리가 등보다 아래로 나온다. 덤으로 fx가 `a.P.hr`를 직접 더해 보간값을 건드린다.

| 시각 | 자세 키 (belly 새 값, 바뀌는 것만) | plant | h | ov |
|---|---|---|---|---|
| 0.0 | loaf (E1로 내려앉음) | none | 기존 | 없음 |
| 1.2~2.4 | 기존 단계 분할(hr 0→2.2, TUCK 유지). 몸 굴리는 중 | none | 기존 | 없음 |
| 2.4 | belly: hr 2.2, cr 0.25, **np 0.45**, hdp −0.1, hdr −1.1, fls −1.2, fle 1.9, frs −1.0, fre 1.8, hls −0.4, hlk 0.6, hrs −0.2, hrk 0.5, hsp 0.55, tb −0.3, tcs 0.2 | none | 기존 | 없음 |
| 2.4~끝 | 뒹굴기 반복(period 2.6) | none | 기존 | hr: 0→+0.22(1.3)→0(2.6), fle·fre: 0→−0.35(0.65)→0(1.3) |

- 핵심은 np +0.45: 뒤집힌 몸에서 목을 배 쪽(=위)으로 굽혀 머리를 등 높이로 올린다. hr를 2.55→2.2로 줄여 반쯤 틀어 눕힌다.
- fx의 `a.P.hr +=` 줄은 지우고 E2 track으로 바꾼다. roll_over(만남)도 같은 belly라 함께 확인.
- 엔진: E1(loaf), E2. 새 키 없음.
- 완료 조건: belly 유지 중 몸통 최저(hips·chest 중 작은 값)가 전체 최저와 0.004 이내(등이 바닥에 닿음). 머리 최저 ≤ 0.02(뺨이 바닥 근처).

| 컷 | 시각 | 보여야 할 것 |
|---|---|---|
| B1 | 1.2 | 식빵에서 굴러가기 시작 |
| B2 | 3.0 | 등이 바닥, 배·앞발 위로. 머리와 몸 사이 틈 없음 |
| B3 | 3.6 | 반대쪽으로 살짝 뒹군 모습(hr 증가) |
| B4 | 측면 3.0 | 옆에서 본 컷: 몸통 아래 빈 공간 없음 |

## 4. 햇볕 쬐며 눕기 sunbathe (M19-2)
특징: ① 옆으로 길게 누워 배를 햇볕에 반쯤 드러냄 ② 다리를 쭉 뻗는다 ③ 가끔 기지개처럼 발을 뻗고 꼬리 끝만 느리게 움직임.
원인: 시퀀스(1.2). 50%는 loaf, 자리를 못 찾으면 loaf만.

새 자세 `sun` (poses.js, side 바탕):
`{ ...side, hr 1.55, cr 0.3, np 0.12, hdp 0.1, hdr −0.4, fls −0.9, fle 0.25, frs −0.6, fre 0.45, hls 0.55, hlk 0.1, hrs 0.8, hrk 0.05, tb −0.1, tcs 0.05, tw 0.03, twf 0.3, eye 0.15 }`

| 시각 | 자세 키 | plant | h | ov |
|---|---|---|---|---|
| 0.0 | 걷기(기존 STEP.walk) | all | 기존 | 없음 |
| 도착+0.0 | loaf (E1) 1.5초 | none | 기존 | 없음 |
| +1.5~+3.0 | sun으로 굴러 눕기(기존 단계 분할) | none | 기존 | 없음 |
| +3.0~끝 | sun 유지 18~40초(r) | none | 기존 | 기지개 1~2회: fls·frs 0→−0.35(0.8)→0(2.0), hls·hrs 0→+0.25 같은 곡선 |
| 끝 | loaf 1.5 | none | 기존 | 없음 |

- 기지개 시각은 steps()에서 r.range로 1~2개 뽑아 track 배열에 넣는다. slowBlink는 기존 fx 유지.
- 자리 없음(freeSpot null)일 때도 제자리에서 sun으로 눕는다. loaf 대체 분기는 지운다.
- 엔진: E1, E2. 새 자세 1개(sun).
- 완료 조건: sun 유지 중 hr ≥ 1.4, 몸통 최저가 전체 최저와 0.004 이내, 머리 최저 ≤ 0.02. 앞다리가 몸 앞쪽으로 뻗음(앞발 z가 가슴 z보다 앞).

| 컷 | 시각 | 보여야 할 것 |
|---|---|---|
| S1 | 도착+1.0 | 식빵으로 앉는 중 |
| S2 | 도착+2.2 | 옆으로 굴러 눕는 중 |
| S3 | 도착+6.0 | 옆으로 길게 누운 모습. 다리 뻗음, 배 반쯤 보임 |
| S4 | 기지개 시각+0.8 | 앞뒤 다리를 쭉 편 순간 |

## 5. 몸 털기 shake (M19-3)
특징: ① 머리부터 털고 몸통, 꼬리 순으로 물결처럼 ② 척추를 축으로 좌우로 비튼다(roll) ③ 털이 부풀고 귀가 펄럭인다.
원인: 회전축(1.2). yaw(hy·hdy)로 도리도리. 진폭도 작고 머리·몸이 같은 위상.

| 시각 | 자세 키 | plant | h | ov (w = 36 rad/s, 약 5.7Hz) |
|---|---|---|---|---|
| 0.0 | stand + fsp 0.1, hsp 0.1 (다리 살짝 벌림) | all | 기존 | 없음 |
| 0.4~0.75 | 유지 | all | 기존 | 머리만: hdr = 0.55·sin(w·t)·e, eL·eR = 0.4·\|sin\|·e |
| 0.6~1.15 | 유지 | all | 기존 | 몸통: cr = 0.32·sin(w·t − 1.0)·e, hr = 0.14·sin(w·t − 1.8)·e, puff = 0.6·e |
| 0.9~1.3 | 유지 | all | 기존 | 꼬리: ts = 0.35·sin(w·t − 2.6)·e |
| 1.3~2.1 | stand | all | 기존 | 없음 |

- e는 구간마다 0→1(0.06초)→1→0(0.1초) 봉투. 구간이 겹쳐 머리→몸→꼬리 파동이 된다. period 없음.
- 기존 hy·hdy ov는 지운다. 사인 곡선이라 E2 track 대신 fx로 써도 된다(구간·봉투 표만 지킬 것).
- 엔진: 없음(E2는 선택). 다리가 hr로 옆으로 흔들려도 plant all이 평균을 맞춘다.
- 완료 조건: 0.5초에 |hdr ov| 최대 ≥ 0.45, 0.9초에 |cr ov| ≥ 0.25, hy·hdy ov는 0. 발 접지 오차 ±0.01.

| 컷 | 시각 | 보여야 할 것 |
|---|---|---|
| K1 | 0.52 | 정면: 머리가 크게 옆으로 기운 순간, 귀 펄럭 |
| K2 | 0.85 | 정면: 가슴이 머리와 반대 방향으로 비틀림, 털 부풂 |
| K3 | 1.05 | 뒤: 꼬리가 옆으로 휘청 |

## 6. 재채기 sneeze (M19-3)
특징: ① 코가 근질거려 눈을 찡그림 ② 머리를 위로 들며 숨을 들이켬 ③ 머리를 아래로 홱 숙이며 등이 굽는다.
원인: 시퀀스·크기(1.2). 0.3초 hdp 0.35 한 번과 입만.

| 시각 | 자세 키 | plant | h | ov |
|---|---|---|---|---|
| 0.0~0.7 | sit 또는 stand(기존 확률) | sit/all | 기존 | 없음 |
| 0.7~1.3 근질 | 유지 | 같음 | 기존 | eye −0.6, eL·eR 0.2, mouth 0.1, hdr = 0.06·sin(t·30) |

## 7. 꼬리 쫓기 tailChase (M19-3)
특징: ① 몸을 C자로 굽혀 머리와 꼬리를 마주 보게 ② 꼬리 끝이 머리 쪽으로 온다 ③ 머리가 꼬리를 보며 그 방향으로 빙글빙글, 발이 종종걸음.
원인: 자세값·시퀀스(1.2). 펴진 몸·꼬리로 yaw만 돌고 다리가 미끄러진다.

새 자세 `chase` (poses.js, crouch 바탕, 머리가 +x 쪽):
`{ ...crouch, hy 0.2, cy 0.5, ny 0.9, hdy 0.45, hdp 0.1, ts −1.1, tcs −0.28, tb 0.15, tw 0, eL 0, eR 0, pupil 0.95 }`
- 부호 규칙(1.1): 머리 +x(cy·ny·hdy +)이면 꼬리 끝도 +x로 와야 하므로 ts·tcs는 −. 회전은 a.yaw 증가(머리 쪽).
- 좌우 판은 r.chance(0.5)로 고르고 모든 yaw 계열 키와 회전 방향 부호를 함께 뒤집는다.

| 시각 | 자세 키 | plant | h | ov |
|---|---|---|---|---|
| 0.0~0.6 | chase (꼬리 발견, 엉덩이 쳐다보기) | all | 기존 | 없음 |
| 0.6~끝 회전 | chase 유지, spinStep 2~4바퀴, 5~7 rad/s | all | 기존 | 종종걸음: fls·hrs = 0.3·sin(φ), frs·hls = −0.3·sin(φ), φ = 회전각×4 |
| 회전 중 | (r로 뽑은 0.8~1.3초 간격) | all | 기존 | 앞발 휘두르기: fls 0→−0.7(0.12)→0(0.3), 쪽발은 머리 쪽 |
| 끝 | stand 0.4 → sit 1.5~2.5 | all/sit | 기존 | 없음 |

- spinStep의 ov tw·twf는 지운다(꼬리를 흔들지 않고 머리 쪽에 고정). 휘두르기 시각은 steps()에서 r로 만든다.
- 엔진: 없음(spinStep 수정은 explore_actions.js 안). 새 자세 1개(chase).
- 완료 조건: chase에서 머리–꼬리끝 수평 거리가 stand 대비 40% 이하. 회전 중 네 발 중 최저가 바닥 ±0.01.

| 컷 | 시각 | 보여야 할 것 |
|---|---|---|
| T1 | 0.5 | 위에서: 몸 C자, 머리가 꼬리를 봄 |
| T2 | 1.2 | 회전 중, 꼬리 끝이 머리 옆 |
| T3 | 휘두르기 시각+0.12 | 앞발이 꼬리 쪽으로 뻗은 순간 |

## 8. 꼬리 탁탁 tailFlick (M19-4)
특징: ① 꼬리를 바닥에 길게 놓는다 ② 끝부분을 들었다가 바닥에 탁 내리친다 ③ 불규칙한 간격, 짜증 난 귀.
원인: ov 축(1.2). tw는 좌우 파동이라 바닥을 쓸고, loaf의 tcs 0.42가 꼬리를 몸에 만다.

| 시각 | 자세 키 | plant | h | ov |
|---|---|---|---|---|
| 0.0~0.5 | sit 또는 loaf + 꼬리 extra: ts 0.7, tcs 0.04, tw 0, tb = 바닥 놓임값 | sit/none | 기존 | 없음 |
| 0.5~끝 | 유지 2.5~4초 | 같음 | 기존 | 탁 1회(0.45초): tb 0→+0.3(0.3 들기), →0(0.38 내리침), tc 0→+0.1(0.3)→0(0.38) |
| 탁 사이 | 쉼 0.3~0.9초(r) | 같음 | 기존 | 0. eL·eR 0.25 내내 |

- 바닥 놓임값: 자세·체형마다 꼬리 끝 최저가 바닥 위 0~0.008이 되는 tb. 시험에서 한 번 찾아 상수로 둔다(초기값 sit −0.1, loaf −0.25).
- ov는 0 이상만 쓴다(아래로 더 누르면 안전망이 몸을 들어 올림). 내리침은 0.08초 안(빠른 낙하)이 핵심.
- 탁 시각 배열은 steps()에서 r로 만든다. 엔진: E2.
- 완료 조건: 쉼 구간에 꼬리 최저 0~0.008, hFinal 변화 ≤ 0.002(몸이 안 들썩임). 들기 정점에서 꼬리 끝 ≥ 0.05.

| F2 | 첫 탁+0.3 | 꼬리 끝이 들린 순간 |

## 9. 모서리에 뺨 비비기 cheekRub (M19-4)
특징: ① 뺨·턱을 모서리에 댄다(지금 좋음) ② 이어서 몸통 옆구리가 모서리를 스치며 지나간다 ③ 꼬리를 세워 끝을 모서리에 감듯 지난다.
원인: 시퀀스(1.2). 머리만 비비고 p↔q를 오가므로 몸이 모서리를 지나지 않는다.

경로(explore_actions.js): 모서리 c = edgePoint(o, a, 0.12, true). 접근점 p = 모서리 대각 바깥 0.28(기존).
지나감 점 s = c에서 한 변을 따라 0.35 간 바깥점(변 법선으로 0.10 띄움). 몸 기울임 방향 sg = 이동 방향 × (o 중심 − 고양이)의 y 부호.

| 시각 | 자세 키 | plant | h | ov |
|---|---|---|---|---|
| 0.0 | 걷기 p, face c, stand 0.4 (기존) | all | 기존 | eye 0.4 |
| 뺨 0.9초 | rubStep 기존(c로 0.3 전진) | all | 기존 | hdr·hy·hdp 기존 |
| 옆구리 1.2초 | stand + tb 1.3, tc −0.12 (꼬리 세우고 끝 갈고리) | all | 기존 | 이동 c→s 0.35 m/s: hr = 0.12·sg·k, cy = −0.3·sg·k, hdr = 0.3·sg·k, ts = 0.4·sg (꼬리 끝이 모서리 쪽) |
| 돌기 | face(c 방향), 0.5초 | all | 기존 | 없음 |
| 반복 | 반대 면으로 같은 순서 2~3회(sg 부호 반전) | all | 기존 | 위와 같음 |
| 끝 | sit 1.8 (기존) | sit | 기존 | eye 0.5 |

- k = sin(π·진행률). 옆구리 단계는 새 `flankStep(x, z, dur, sg)`로 rubStep 옆에 둔다(keepPose 걷기, 다리는 기존 걸음).
- world.resolve가 몸을 밀어낼 수 있으니 띄움 0.10을 먼저 쓰고, 막히면 0.12로 늘린다.
- 엔진: 없음(explore_actions.js 안). E2 불필요.
- 완료 조건: 옆구리 단계 중 고양이 중심–모서리 최단거리 ≤ 0.16(성체), 기울임 hr ov 부호가 모서리 쪽.

|---|---|---|
| C1 | 뺨+0.45 | 뺨을 모서리에 댄 모습(기존과 같음) |
| C2 | 옆구리+0.5 | 어깨·옆구리가 모서리에 붙어 지나감, 몸 모서리 쪽 기움 |

## 10. 꾹꾹이 knead (M19-4)
특징: ① 앞발을 바닥에 댄 채 번갈아 눌렀다 뗀다(살짝) ② 누를 때 몸이 그쪽으로 조금 실린다 ③ 눈 반감김, 일정한 리듬.
원인: 자세값(1.2). kneadL·R이 sit의 fls 1.04를 −0.35로 덮어 어깨가 크게 휘둘린다.

자세 수정 (poses.js, sit 대비 차이로 쓴다):
- kneadL: `{ ...sit, fls: sit.fls − 0.16, fle: −0.45, np 0.5, hdp 0.5, eye 0.4 }` (kneadR은 frs·fre)
- kneadL·R 이름은 유지한다(기존 기준값 시험이 이름을 참조할 수 있음).

| 끝 | loaf(E1) 또는 sit 1.5~3 | none/sit | 기존 | 없음 |

- 박 길이를 0.42로 줄이고 보간(4.2)이 따라오게 한다. 드는 발 높이는 plant sit(앞발 최저 맞춤)이 자동으로 정한다.
- 누름 ov는 박마다 같은 모양이라 E2 track(period = 한 박)으로 쓴다. 디딘 발 쪽 부호만 번갈아 바꾼다.
- 엔진: E2.
- 완료 조건: 든 발 최저 0.008~0.02(성체), 디딘 발 ±0.003. 어깨 각 변화 ≤ 0.2rad.
