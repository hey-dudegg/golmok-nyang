## 1. 공통 사실(코드에서 확인)
- 일정은 시계(clock.weights)가 고른다. 여기서 `score(c)`의 c는 **시계용 문맥**이라 `a.slot`이 없다(pickSlot 주석 "시계 대역은 존재만 본다").
  → "직전 행동이 상자 안"을 점수로 걸 수 없다. 그래서 2번은 새 행동이 아니라 상자 행동의 **끝맺음 변형**으로 둔다.
- 감정 편향: `m = 1 + Σ w·(emo−0.5)·2`, clamp 0.4~1.8 (clock.js 104줄). 최근 행동 배수 0.3/0.6/0.85/1.3.
- 지점 행동은 `PROP_ACTION_KEYS`에 넣어야 최근 반복 금지·구간 경계 규칙(bOK)이 적용된다. 기능 스위치 꺼지면 registerPropActions가 지운다.
- `approach()`는 걷기 속도 1.1 고정. `zoom`은 STEP.walk 속도 3.2, 걷기 자세 tb 0.35(속도>2).
- `PS.dismount(true)`: 상자는 대기 0.1초 + 빠른 도약(HOP.fastSpeed 1.0), 차 밑은 낮은 걸음 속도 2.0.
- 털 세움 키 `puff`는 **이미 있다**(standPose puff 0, 셰이더 furPuff, 보간 속도 3 = 다른 키 4.2보다 느림). hiss 자세가 puff 1.
- 옆걸음 이동은 `moveTo(..., { keepPose, crab: true })`가 이미 있다(REACTIONS.puff_side). crab은 몸 방향을 고정하고 그대로 미끄러진다.
- 슬롯의 `poses` 배열은 **코드에서 읽는 곳이 없다**(문서·자기점검용). 실제 자세는 행동 steps가 정한다.
- 담: WALL { l 1.8, w **0.22**, h 0.80 }. 캣타워 top에서 이미 'sit'을 쓴다(높은 곳 앉기 선례, towerLookout).

## 2. 도망쳐 숨기 fleeHide (M23-2)
**모습**: 흠칫 웅크림(귀 젖힘·털 약간) → 가까운 숨을 곳으로 전속력 → 차 밑/캣타워 굴에 들어가 납작 → 빼꼼 → 천천히 나옴.

**트리거·점수** (prop_actions.js PROP_ACTIONS에 추가)
```js
fleeHide: { label: '깜짝 놀라 숨는 중',
  score: (a) => (nearHide(a) ? 0.04 + (1 - a.p.bold) * 0.12 + (a.kitten ? 0.05 : 0) : 0), steps: (a, r) => [...] }
// clock.js EMO_BIAS
fleeHide: { scared: 1.4, wary: 0.6, calm: -0.5, playful: -0.4 }
```
- `nearHide(a)`: `pickSlot(a,'underHide',{as:'fleeHide'})`, `pickSlot(a,'towerDen',{as:'fleeHide'})` 중 **가까운 쪽**(접근점 거리). 3.0m 넘으면 null.
  시계 문맥에서는 pickSlot이 존재만 보므로 거리 조건은 실행 때(steps)만 적용한다.
- 숨을 곳이 없으면 점수 0. 숨을 곳 없는 겁은 기존 `freeze`(scared 1.2)가 맡는다.

**단계**
| # | STEP | 시간 | 내용 |
|---|---|---|---|
| 1 | `STEP.pose('crouch', r.range(0.35, 0.6), { eL: 0.85, eR: 0.85, pupil: 1, puff: 0.6, tb: -0.3, tw: 0 })` | 0.35~0.6s | 흠칫. 시작 시 `a.say('!')`(call) |
| 2 | `STEP.face(접근점 쪽 yaw)` | ~0.2s | 돌아서기 |
| 3 | `STEP.walk(S.ax, S.az, 3.2, { timeout })` + `PS.check(S)` | 거리/속도 | approach에 속도 인자 추가해서 사용 |
| 4 | `PS.enter(S)` | 기존 | 차 밑: hideLow 낮은 걸음, 굴: 걸어 들어감 |
| 5 | `STEP.pose('hideLow' 또는 굴이면 'loaf', r.range(4, 8), { eL: 0.6, eR: 0.6, puff: 0.3 })` | 4~8s | 납작 숨기 |
| 6 | `peek(r.range(6, 15))` (underHide·towerDen의 peek와 같은 것) | 6~15s | 빼꼼 |
| 7 | `PS.dismount(false)` | 기존 | 천천히 나옴 |
- 바꿀 함수: `approach(a, S, speed = 1.1)`·`pickApproach(a, action, opt)`에 `opt.speed` 전달. timeout 식의 1.1도 speed로.
- a.slot.action은 슬롯 것('underHide'/'towerDen')이 되므로 숨은 뒤 교감 반응·"이어서" 분기는 기존 그대로 동작한다.
- 대체: steps 시점에 두 슬롯 모두 실패(점유·막힘)하면 `[1번 웅크림, STEP.walk(멀어지는 점, 3.2), STEP.pose('crouch', 2, {eL:0.6,eR:0.6})]` (a.farFrom 사용).
- 자세 전환: crouch(plant all) → 걷기 stand → hideLow(none, 낮음). 모두 기존 경로(planPose)라 새 엔진 없음.
- 등록: props.js `PROP_ACTION_KEYS`에 `fleeHide`. 캣타워 묶음(TOWER_KEYS)에는 넣지 않는다(공포 상황은 묶음 제한 예외).
- 비율 영향 추정: 평소 scared≈0.5면 m≈1, 점수 0.04~0.21 → 전체의 1% 안팎. 소심(bold 0.2)+겁(0.9)이면 ~0.38(×1.8)로 상위 5위권.
  underHide(scared 1.0)와 수요를 나눠 갖는다(underHide 비중 소폭 감소 예상).

## 3. 상자 밖으로 뛰쳐나오기 (M23-2)
**모습**: 상자 안(앉기·잠·빼꼼)에서 갑자기 몸을 낮춰 엉덩이 들썩 → 벽 넘어 빠르게 튀어나옴 → 우다다 2~3구간 → 멈춰 앉음.

**방식**: 새 행동 키 없음(1장 이유). 상자 행동 5곳(crateSit·crateNap·giftPeek·giftSniff의 끝 `PS.dismount(false)`와 "이어서" 분기)을 `...crateExit(a, r, pAdd)`로 바꾼다.
```js
// prop_actions.js
export const HOP = { slow: 1, speed: 0.7, fastSpeed: 1.0, bolt: null }; // bolt: null=확률대로, 1=항상, 0=안 함(어드민·촬영용, slow와 같은 손잡이)
const crateExit = (a, r, pAdd = 0) => { const p = HOP.bolt ?? clamp(0.08 + a.p.playful * 0.3 + (a.kitten ? 0.15 : 0) + pAdd, 0, 0.55);
  return r() < p ? boltSteps(a, r) : [PS.dismount(false)]; };
```
- pAdd: giftPeek·giftSniff +0.12(빼꼼 뒤 튀어나오기), crateNap −0.05(막 깬 뒤라 덜 튐). crateSit 0.
- 확률 추정: 보통 성격(playful 0.5) 23%, 장난꾸러기 새끼 ~50%.

**boltSteps 단계**
| # | STEP | 시간 | 내용 |
|---|---|---|---|
| 1 | `STEP.track('crouch', r.range(0.4, 0.8), { pupil: 1, eL: 0.1, eR: 0.1, ...CRATE_TAIL }, { hp: [[0,0],[0.15,-0.06],[0.3,0]] }, { period: 0.3 })` | 0.4~0.8s | 엉덩이 들썩(준비) |
| 2 | `PS.dismount(true)` | ~0.5s | 기존 빠른 나오기(벽 위 도약 → 접근점) |
| 3 | `STEP.walk(p1, 3.2)`, `STEP.walk(p2, 3.2)` (r.int(2,3)개, `a.randomPoint(r, 2.4)`) | 구간당 ~1s | zoom과 같은 속도·걷기 자세 |
| 4 | `STEP.pose('stand', 0.6)`, `STEP.pose('sit', 2)` | 2.6s | zoom 끝과 같음 |
- 점들은 steps 시점에 미리 뽑는다(D-19). 상자 쪽으로 다시 가는 점은 `world.resolve` 충돌로 막히니 별도 처리 없음.
- 기존 행동 비율 영향 없음(일정 키가 그대로). 상자 행동 세션의 약 1/4이 끝에 3~5초 더 길어진다.

## 4. 등 세우고 털 세워 옆걸음 archSide + 새 자세 arch (M23-4)
### 4.1 자세 arch (render/poses.js POSES에 한 줄)
hiss(hp −0.28, cp +0.34)보다 등을 더 높이 굽히고, 다리를 곧게 펴서 몸을 키운다. 입은 닫음(하악은 따로 hiss로).
| 키 | 값 | stand 대비 이유 |
|---|---|---|
| plant | 'all' | 네 발 평균 접지(1.1 엔진 제약). 다리 펴짐이 몸 높이로 바로 이어짐 |
| hp / cp | −0.42 / +0.50 | 등 아치(부호: hp − 엉덩이쪽 들기, cp + 가슴 숙임). bodyDelta(stand→arch)=0.50 ≤ ROT_LIMIT → 1단계 |
| np / hdp | 0.10 / 0.15 | 머리는 등 아래 높이로 살짝 낮춤 |
| fls·frs / fle·fre / fsp | −0.10 / 0.05 / 0.06 | 앞다리 곧게, 약간 벌림 |
| hls·hrs / hlk·hrk / hsp | −0.10 / 0.20 / 0.06 | 뒷다리 곧게(stand −0.28/0.5보다 펴짐) |
| tb / tc / tw / twf | 1.35 / 0.04 / 0.02 / 0.5 | 꼬리 수직에 가깝게, 흔들림 거의 없음 |
| eL·eR / pupil / eye / mouth | 0.7 / 1 / 1 / 0 | 귀 반쯤 젖힘, 동공 확대 |
| puff | 1 | 털 세움(기존 키) |
- 값은 시작값이다. 개발자는 `--poses stand,arch --measure`·`--poses sit,arch --measure`로 확인 후 ±0.1 안에서 조정한다.
- 접지 조건: plant 'all'이라 네 발 평균이 바닥. 아치로 앞·뒤 발 높이가 어긋나면 한쪽이 뜬다 → 6장 "발 높이 차" 측정으로 확인.
  머리·꼬리가 몸보다 낮지 않으므로 안전망(전체 들어올림)은 걸리지 않아야 한다.
- puff 보간 3은 조금 느리다(약 1초에 90%). 이번에는 그대로 두고 측정만 한다. 느리면 시작 0.3초 `ov.puff` 보탬(트랙)으로 보완(엔진 변경 없음).
- 전환 경로(D-129): stand→arch 1단계, sit→arch(cp 차 0.92) 2단계 섞기(접기 없음), loaf→arch는 LOW→비LOW·d 0.55라 planSink 섞기. 새 분기 불필요.

### 4.2 행동 archSide (core/explore_actions.js EXPLORE_ACTIONS)
```js
archSide: { label: '등 세우고 옆걸음',
  score: (a) => { const o = a.nearestCat(1.2); if (o && !family(a, o)) return (a.p.bold * 0.5 + a.p.grumpy * 0.4) * 0.5;
                  return a.kitten ? a.p.playful * 0.15 : 0; }, steps: (a, r) => [...] }
// clock.js EMO_BIAS
archSide: { wary: 0.8, scared: 0.5, grumpy: 0.4, playful: 0.3, calm: -0.6 }
```
- family는 hissAt과 같은 조건(엄마·자식 제외). 새끼 놀이형은 이웃 없어도 나온다(새끼들의 "핼러윈 옆걸음" 장난).
- clock.js 102줄의 새끼 감쇄(hissAt ×0.3)는 archSide에 적용하지 않는다.

**단계 (위협형: 이웃 o 있음)**
| # | STEP | 시간 | 내용 |
|---|---|---|---|
| 1 | `STEP.call`: `sgn = r.chance(0.5) ? 1 : -1`, `a.yawTarget = a.yawTo(o) + sgn·π/2`, `a.lookAt = o` | - | 옆구리를 상대에게 |
| 2 | `STEP.track('arch', 0.8, null, { puff: [[0,0.4],[0.3,0]] })` | 0.8s | 등 세움(초반 털 보탬) |
| 3 | `STEP.call(moveTo(멀어지는 점, 0.35, { keepPose: 'arch', crab: true }))` | - | 이동 방향 = 상대 반대(yawTo(o)+π), 거리 r.range(0.3, 0.45). bold>0.6이면 상대 쪽(최소 0.6m 남김) |
| 4 | `STEP.track('arch', r.range(1.8, 2.6), null, { fsp: [[0,0.06],[0.25,0.16],[0.5,0.06]], hsp: [[0,0.16],[0.25,0.06],[0.5,0.16]] }, { period: 0.5 })` | 1.8~2.6s | 옆으로 딛는 발 벌림 번갈아(옆걸음 다리 표현) |
| 5 | (r < 0.3 + grumpy·0.5) `STEP.call(say('하악!'))`, `STEP.pose('hiss', 1.2)` | 1.2s | 하악질로 이어짐(경계 흐름 연결) |
| 6 | `STEP.call(lookAt = null)`, `STEP.walk(멀어지는 점 0.8m, 1.1)`, `STEP.pose('sit', 2, { eL: 0.4, eR: 0.4, puff: 0.3 })` | ~4s | 물러나 진정 |
- 새끼 놀이형: 1번 yaw는 r로 임의, 3~4번 이동을 좌우 번갈아 2회(0.25m씩, 속도 0.6), 5번 없음, 6번 대신 `STEP.pose('crouch', 0.6)` 뒤 50%로 `ACTIONS.zoom.steps(a, r)` 이어 붙임.
- crab 이동은 몸이 옆을 보고 상대 축을 따라 미끄러진다 = 몸 기준 **옆걸음**. 걷기 다리 흔들림(gait)은 앞뒤 방향이라 4번 트랙으로 보완한다.
  보완이 어색하면 그 원인은 엔진 제약(관절에 옆 회전 없음)으로 기록하고 이동 속도를 0.25로 낮춘다.
- 하악과의 관계: hissAt(0.7m 안, grumpy)은 그대로. archSide는 0.7~1.2m 거리의 앞 단계로 보이게 된다.
- **영향(제안)**: REACTIONS.puff_side(교감 반응, 라벨 "털 세우고 옆걸음")의 `hiss`·`keepPose:'hiss'`를 `arch`로 바꾸면 반응도 같은 모습이 된다 → 8장 팀장 확인.
- 비율 영향 추정: 이웃이 1.2m 안에 있을 때만 성체 점수 0.1~0.45. 평소 전체 1% 미만, 이웃 많은 방에서 hissAt과 비슷한 수준.

## 5. 담 위 앉기 wallSit (M23-3)
**모습**: 담에 올라가 담 방향으로 앉아 두리번 → 가끔 엎드림 → 내려옴. 꼬리는 담 밖으로 늘어뜨림.
- props.js lowwall `top0`·`top1`의 `poses: ['lie']` → `['lie', 'sit']` (문서 값. 코드에서 읽는 곳은 없음).
- 새 행동 키를 둔다(라벨이 "엎드린 중"과 달라야 하므로). crateNap이 crateSit 슬롯을 공유하는 방식 그대로.
```js
wallSit: { label: '담 위에 앉아 구경하는 중',
  stay: (a) => a.slot.action === 'wallLoaf' && a.slot.state === 'on', // 엎드려 있다가 일어나 앉기(내려오지 않음)
  score: (a) => (pickSlot(a, 'wallLoaf', { as: 'wallSit' }) ? 0.15 + a.p.bold * 0.3 + a.p.playful * 0.2 + a.world.day * 0.2 : 0), steps }
// clock.js EMO_BIAS
wallSit: { curious: 0.8, wary: 0.3, scared: -0.7 }
```
| # | STEP | 시간 | 내용 |
|---|---|---|---|
| 1 | (이어서가 아니면) `...ap, PS.mount(S)` | 기존 | wallLoaf와 같은 오르기 |
| 2 | `STEP.pose('sit', r.range(10, 25), WALL_TAIL, look fx)` | 10~25s | towerLookout의 look과 같은 두리번(6~10초마다) |
| 3 | r < 0.35면 `STEP.pose('lie', r.range(6, 15), null, lieFx)` | 6~15s | 엎드리기(sit→lie 전환은 planPose) |
| 4 | `PS.dismount(false)` | 기존 | |
- `WALL_TAIL = { tb: -0.9, tc: 0.08, tcs: 0, ts: 0 }`: 꼬리를 담 밖으로 늘어뜨림. 담 바깥 면을 뚫으면 tb −0.6까지 줄인다(측정).
- 방향: 슬롯 `S.yaw`(담 길이 방향) 그대로 앉는다. 담 폭 0.22m라 길 쪽을 보고 앉으면 엉덩이가 넘칠 수 있다 → 이번엔 담 방향만.
- 등록: `PROP_ACTION_KEYS`, clock.js `PASSIVE_KEYS`(wallLoaf와 같이)에 `wallSit`. 새끼 제외는 pickSlot의 mode 'on' 규칙이 이미 한다.
- 교감 반응: slotReactSteps의 rest는 'on'이면 'lie'라 앉아 있다가 만지면 엎드린다. 자연스러워 그대로 둔다.
- 비율 영향: wallLoaf(0.25+…)와 수요를 나눈다. 담 행동 전체가 약 1.6배로 늘지 않도록 wallSit 기본값을 wallLoaf의 60% 수준으로 잡았다.
